TLDR

A general code-review routine from the Gemini CLI repository. With no PR named, it reviews your working tree: git status, then git diff for unstaged and staged changes, and on a substantial change it asks whether to run npm run preflight first. Given a PR number or URL, it checks the PR out with gh pr checkout, runs npm run preflight to catch automated failures, and reads the PR description and existing comments. It then weighs the changes for correctness, maintainability, readability against the project's style, efficiency, security, edge cases and error handling, and whether tests cover the new code, suggesting extra test cases. Feedback opens with a summary, lists critical findings (bugs, security issues, breaking changes), then improvements and optional nitpicks, explains why each change is requested, and ends with a recommendation. The tone is constructive, and approvals name what the contribution adds. After a PR review it asks whether to switch back to the default branch. None of its steps post the review to GitHub.

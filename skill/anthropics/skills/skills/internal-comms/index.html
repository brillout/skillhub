TLDR

The SKILL.md only works out what kind of message you want and loads one of four guides. A 3P update covers a team's week in three short lines, Progress, Plans and Problems, with metrics where possible, so leadership can read it in under a minute. A newsletter is about 20 to 25 short bullets for the whole company, written as "we", grouped into sections and full of links to the docs, announcements and threads that drew the most attention. An FAQ collects the questions many employees are asking and answers each in a sentence or two, flagging any that need an executive. Anything else, from incident reports to leadership updates, gets general advice: ask about audience, purpose and tone, and lead with what matters most. Where it can, the agent pulls material from Slack, email, Google Drive and calendar, favouring posts with many reactions and widely attended meetings; otherwise it asks you. The formats are Anthropic's, written down in four Markdown files in the skill; to match how your company writes, you edit those files.

When to use this skill

To write internal communications, use this skill for:

  • 3P updates (Progress, Plans, Problems)
  • Company newsletters
  • FAQ responses
  • Status reports
  • Leadership updates
  • Project updates
  • Incident reports

How to use this skill

To write any internal communication:

  1. Identify the communication type from the request
  2. Load the appropriate guideline file from the examples/ directory:
    • examples/3p-updates.md - For Progress/Plans/Problems team updates
    • examples/company-newsletter.md - For company-wide newsletters
    • examples/faq-answers.md - For answering frequently asked questions
    • examples/general-comms.md - For anything else that doesn't explicitly match one of the above
  3. Follow the specific instructions in that file for formatting, tone, and content gathering

If the communication type doesn't match any existing guideline, ask for clarification or more context about the desired format.

TLDR

A debugging command from the engineering plugin of Anthropic's knowledge-work plugins. It asks for whatever you have: the exact error or stack trace, steps to reproduce, what changed recently, logs or screenshots, and expected versus actual behavior. It then works in four steps. Reproduce pins down the behavior, the exact steps and the scope: when it started and who is affected. Isolate narrows it to a component, service or code path and checks recent deploys, config and dependency changes, and the logs. Diagnose forms and tests hypotheses and traces the code path to a root cause rather than a symptom. Fix proposes a change with an explanation, weighs side effects and edge cases, and suggests regression tests. The report covers reproduction, root cause, the fix and prevention. With monitoring connected it pulls logs, error rates, metrics and recent deploys around the time of the issue; with source control, the commits and PRs that touched the affected code; with a project tracker, related bug reports, and it creates a ticket for the fix.

Tips

  1. Share error messages exactly — Don't paraphrase. The exact text matters.
  2. Mention what changed — Recent deploys, dependency updates, and config changes are top suspects.
  3. Include context — "This works in staging but not prod" or "Only affects large payloads" narrows things fast.

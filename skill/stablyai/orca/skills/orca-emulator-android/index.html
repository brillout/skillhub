orca-emulator-android

Use it when
you work in Orca and need an Android emulator or USB-debugging phone driven, on Windows, Linux or macOS
It does
attaches a device or boots a virtual one, then taps, swipes, types, presses buttons, rotates, installs an APK, launches an app and grants or revokes permissions
You get
the device live in Orca's emulator pane, its accessibility tree from uiautomator, and recent logcat lines as parsed entries
Needs
Orca, adb from the Android SDK, and the SDK emulator for virtual devices; build the APK with Gradle first
Unlike orca-emulator
the repo's iOS skill, which needs a Mac, this also works on a headless Orca server or an SSH host

Needs Orca, Stably's desktop app for running coding agents in parallel, and adb from the Android SDK.

TLDR

Like the repo's iOS skill, the SKILL.md is a stub that resolves the right Orca executable, avoiding the GNOME screen reader of the same name on Linux, and loads the guide that matches the installed Orca version. Orca's Android backend shells out to adb, plus the SDK emulator for virtual devices, with no extra streaming server. The guide maps each goal to an orca emulator command, and anything else can go through as a raw adb shell command. Coordinates run from 0 to 1 from the top left, swipes go straight from the first point to the last, and typing is ASCII without newlines, so text in other scripts goes through the app's own interface. One device is active per worktree, and it warns that the all-worktrees selector also unscopes commands that change things. Camera and sensor injection aren't covered. When done, the agent stops the helper, which otherwise holds the device until Orca quits.

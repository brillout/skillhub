TLDR

ego lite is a Chromium browser designed for people and AI agents to use together, so the agent can work in the sites you're already signed into. Its description tells the agent to reach for it whenever a browser is needed, ahead of built-in browsers and other web tools. This skill is only a bootstrap: before any browser task the agent runs ego-browser skill and follows the guide that command prints, which matches the installed version, and runs it again after an upgrade or when told to. If the guide's end marker is missing, the output was cut off, so it saves it to a file and reads it in parts. Two references cover installing or upgrading ego lite, and clearing cookies, cache or storage, which it reads first because some clears reach the whole browser profile.

ego-browser

Before any browser task, run:

ego-browser skill

and follow its output. It prints the usage guide that matches the installed ego lite version. Run it again after ego-browser upgrade, or when any output says to.

The guide ends with a line starting [ego-browser:skill] end of guide. If that line is missing, the output was truncated: save it to a file and read the file in parts, for example ego-browser skill > "$TMPDIR/ego-browser-skill.md", or ego-browser skill > "$env:TEMP\ego-browser-skill.md" in PowerShell.

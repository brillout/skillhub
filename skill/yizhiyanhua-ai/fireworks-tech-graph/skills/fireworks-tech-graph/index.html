fireworks-tech-graph

Use it when
you want an architecture, UML, agent, cloud or workflow diagram from a description; not photos, raster art or statistical charts
It does
renders the diagram as SVG with a bundled Python script, checks it for collisions, broken arrows and cut-off labels, then repairs what fails
You get
an SVG, plus a PNG, a pan-and-zoom offline HTML file or an animated GIF when you ask
Styles
twelve, Flat Icon by default; styles 9 to 12 follow C4, cloud, event and observability conventions
Needs
Python 3

TLDR

SVG is the main output; PNG, a single offline HTML page with pan, zoom and downloads, and GIF animation are made from it. For eleven of its twelve styles the agent writes a JSON description that a bundled script validates and renders; Style 8, Dark Luxury, is written as SVG directly. A check command looks at marker references, overlaps, geometry and composition, and a strict text mode makes sure every label shows in full. The agent then views the PNG at reading size, if it can view images, for missing text, contrast, spacing, clipping, arrow direction and crossings, and repairs failures by element ID, changing approach after two unchanged failures. It widens or splits a crowded diagram rather than shrinking the text. GIF motion works on the supported diagram layouts, at 960px and 20fps by default. Styles 9 to 12 check facts before layout and don't invent responsibilities, protocols or metrics. It ends by reporting file paths, dimensions, the visual review and remaining limits, and never publishes or sends a diagram without separate permission.

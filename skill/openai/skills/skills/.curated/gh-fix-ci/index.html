gh-fix-ci

Use it when
a pull request's GitHub Actions checks are failing and you want them diagnosed and fixed
It does
checks gh is logged in, finds the PR for the current branch or the one you name, and pulls the failing runs' logs with a bundled Python script
You get
each failing check's name, run URL and log snippet, a fix plan to approve, then the fix with a summary of diffs and tests
Needs
the GitHub CLI, gh, logged in with repo and workflow scopes, and Python for the script
Skips
checks run by other CI providers such as Buildkite, reporting only their URL
Unlike diagnose-ci-failures
Warp's skill, which stops at a fix plan, this one carries out the plan after you approve it

TLDR

A CI-repair loop from OpenAI's catalog of Codex skills. The agent confirms gh is authenticated, asking you to run gh auth login if not, resolves the PR (the current branch's by default, or a number or URL you give) and inspects its checks. A bundled script, inspect_pr_checks.py, finds the failing checks, fetches their GitHub Actions logs, falls back to job logs while a run is still in progress, and extracts the failure snippet; it can print JSON and exits non-zero while failures remain. Plain gh commands are the fallback. Checks from other providers are labelled external and only their details URL is reported. The agent summarizes each failure, calls out missing logs, and drafts a plan, through a create-plan skill when one is available or inline otherwise. Nothing changes until you approve. Then it applies the plan, summarizes the diffs and tests, asks whether to open a PR, and suggests re-running the tests and gh pr checks. The openai/skills repository is marked deprecated; its README points to openai/plugins for current Codex skills.

playwright

Use it when
the agent needs a real browser from the terminal: open pages, fill forms, extract data, take screenshots or debug a UI flow
It does
runs Playwright's command-line tool through a bundled wrapper that calls it with npx, so no global install is needed
Works by
opening a page, taking a snapshot that gives each element a short ref like e15, acting on refs, and snapshotting again after anything changes
You get
screenshots, PDFs and traces when useful, kept under output/playwright/
Needs

Unlike Microsoft's playwright-cli

TLDR

OpenAI's short skill for Playwright's command-line tool, written for Codex. Before proposing commands the agent checks that npx is available and, if not, asks you to install Node.js. It points a PWCLI variable at the bundled playwright_cli.sh, which runs @playwright/cli through npx; a global install works too. Work follows one loop: open a page, snapshot it to get element refs, click, type, fill or press using refs from the latest snapshot, and snapshot again after navigation, modals, tab switches or big UI changes, because refs go stale. Recipes cover filling and submitting a form, tracing a UI flow to debug it, and working across tabs; --headed shows the browser when a visual check helps. Its guardrails: never reference an element without a fresh snapshot, prefer explicit commands over eval and run-code, keep artifacts in output/playwright/, and use CLI commands rather than @playwright/test specs unless you ask for tests. A command reference and a workflows and troubleshooting file are opened only when needed. The openai/skills repository is marked deprecated; its README points to openai/plugins for current Codex skills.

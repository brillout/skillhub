jupyter-notebook

Use it when
you want a new .ipynb notebook, or rough notes, a script or a messy notebook turned into one that others can read and re-run
It does
picks an experiment or a tutorial layout, scaffolds the file from a bundled template with a Python script, then fills it with small cells, each explained in Markdown
You get
a notebook with a descriptive filename, run top to bottom when the environment allows, or a note on how to validate it locally
Needs
uv and Python 3.12 for the scaffold script, which uses only the standard library; JupyterLab and ipykernel only to execute the notebook
Runs from
Codex's skills folder: its script path assumes ~/.codex/skills unless CODEX_HOME says otherwise

TLDR

A notebook skill from OpenAI's catalog of Codex skills. It has two kinds of notebook: experiment, for exploratory, analytical or hypothesis-driven work, and tutorial, for step-by-step teaching aimed at an audience; editing an existing notebook counts as a refactor that keeps its intent. The agent first pins down the kind, the objective, the audience and what done looks like, then runs new_notebook.py, which loads the matching template, sets the title cell and writes the notebook, so no raw notebook JSON is written by hand. Each code cell does one step, with a short Markdown cell giving its purpose and expected result, and short summaries replace large, noisy outputs. Experiments and tutorials each follow their own patterns file, raw JSON edits go through a notebook-structure guide first, and a quality checklist closes the work. In existing notebooks it prefers targeted edits to rewrites and reorders cells only when that improves the top-to-bottom story. Intermediate files go in tmp/jupyter-notebook/ and are deleted when done. The openai/skills repository is marked deprecated; its README points to openai/plugins for current Codex skills.

playwright-interactive

Use it when
the agent is building a local web or Electron app in Codex and should check its own work in a real browser before calling it done
It does
keeps Playwright's browser, page and Electron handles alive in a js_repl kernel, reloading for renderer changes and relaunching for main-process ones
Checks against
a QA inventory written first: every requirement, control, state and claim it means to sign off on, plus at least two off-happy-path scenarios
You get
signoff only after functional QA with real input, a separate visual pass backed by screenshots, viewport-fit checks and a short exploratory pass
Needs
Codex with js_repl enabled, run with --sandbox danger-full-access for now, and Playwright installed with npm in the project
Unlike playwright
OpenAI's CLI-based skill, which drives any site command by command, this one is a QA loop for your own app with handles kept alive

Codex only: needs its js_repl feature enabled and, for now, Codex started with sandboxing off (--sandbox danger-full-access).

TLDR

A QA workflow from OpenAI's catalog of Codex skills, built on Codex's js_repl tool, a persistent JavaScript kernel. Setup installs Playwright in the project; a bootstrap cell loads it once, and top-level handles for the browser, its pages and the Electron app are reused across iterations. Web apps run at an explicit viewport by default (1600×900, or 390×844 with touch for mobile), with a separate native-window pass when window size or DPI matters; Electron always runs as a native window. Before testing, the agent writes a QA inventory from your requirements, what it actually built and the claims it plans to make, and maps every item to a check. Functional QA uses real clicks, keys and taps, takes each toggle through its full cycle and ends with 30 to 90 seconds of exploration. Visual QA is a separate pass over the initial viewport, the densest and post-interaction states and a smaller window, looking for clipping, contrast, spacing and weak aesthetics, with screenshots as evidence that metrics can't overrule. Cleanup is manual: leaving Codex doesn't close the browser or Electron app. The openai/skills repository is marked deprecated; its README points to openai/plugins for current Codex skills.

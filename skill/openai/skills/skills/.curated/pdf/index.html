pdf

Use it when
you're creating or reviewing a PDF where layout and visuals matter
It does
builds PDFs with reportlab, extracts text with pdfplumber or pypdf, and renders pages to PNG with Poppler to look at them
You get
a finished PDF that has passed a page-by-page visual check, with intermediate files removed
Unlike Anthropic's pdf
it has no recipes for merging, splitting or filling forms; it centres on generating PDFs and checking how they render
Needs
Python with reportlab, pdfplumber and pypdf, and Poppler's pdftoppm; it installs them if missing

TLDR

A short workflow from OpenAI's catalog of Codex skills. The agent prefers visual review: it renders PDF pages to PNG images with pdftoppm and inspects them, because text extraction with pdfplumber or pypdf is only for quick checks and says nothing reliable about layout. New documents are built with reportlab, and after each meaningful change the pages are rendered again and checked for alignment, spacing and legibility. Its quality bar asks for consistent typography, margins and section hierarchy; sharp, aligned and labelled charts, tables and images; no clipped or overlapping text, broken tables, black squares or unreadable glyphs; plain ASCII hyphens instead of Unicode dashes; and citations with no leftover tool tokens or placeholders. It doesn't deliver until the latest render shows no defects. Intermediate files go in tmp/pdfs/ and are cleaned up. If a dependency can't be installed, it tells you which one is missing and how to install it yourself. The openai/skills repository it comes from is now marked deprecated; its README points to openai/plugins for current Codex skills.

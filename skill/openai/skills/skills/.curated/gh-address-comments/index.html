gh-address-comments

Use it when
reviewers have left comments on the open pull request for your current branch and you want them worked through
It does
checks gh is logged in, runs a bundled Python script that prints every comment and review thread, then numbers them with what each fix would take
You choose
which numbered comments to address; the agent applies fixes for those only
Needs
the GitHub CLI, gh, logged in with repo and workflow scopes, and Python for the script
Unlike respond-to-pr-comments-in-blocklist
Warp's skill, which also posts replies and resolves threads after you approve, this one stops at the code fixes

TLDR

A short PR-review loop from OpenAI's catalog of Codex skills. The agent confirms gh is authenticated, asking you to run gh auth login if not, and runs gh with elevated network access, retrying with escalated permissions if a sandbox blocks it. A bundled script, fetch_comments.py, prints all comments and review threads on the open PR for the current branch. The agent numbers each one with a short summary of what fixing it would take and asks which to address, then applies the fixes for those you pick. If gh hits an auth or rate-limit problem midway, it asks you to log in again and retries. The SKILL.md has no step for replying on GitHub, resolving threads or committing. The openai/skills repository is marked deprecated; its README points to openai/plugins for current Codex skills.

imagegen

Use it when
a project needs a raster asset, new or edited: a photo, illustration, texture, sprite, mockup or transparent cutout
It does
decides between a new image and an edit, labels each input image's role, rewrites your prompt as a labelled spec, generates, inspects and changes one thing at a time
You get
the chosen image copied into your workspace, plus the final prompt and which mode made it; an existing file gets a versioned sibling, not an overwrite
Two modes
Codex's built-in image_gen tool by default; a bundled Python CLI with generate, edit and batch commands only when you ask for it
Skips
simple shapes, diagrams and icons better made in SVG, HTML/CSS or canvas, and anything that should match an existing icon set or logo system in the repo

Made for Codex's built-in image_gen tool; in another agent you must ask for its CLI mode, which needs an OPENAI_API_KEY. Prompts and input images go to OpenAI.

TLDR

OpenAI's image-generation skill, a system skill that the latest Codex installs automatically. The agent first decides whether the request is a new image or an edit (reference images alone mean a new one) and whether it needs one asset or many, then collects the prompt, exact text, constraints and input images, labelling each image as a reference, the edit target or a compositing input. The prompt becomes a short labelled spec: a use case from a fixed list of 16 (product mockup, logo, style transfer, background extraction and others), asset type, subject, style, composition, lighting, palette, verbatim text, constraints and things to avoid. Detail is added only to generic prompts, never extra characters, brands or slogans, and edits restate what must stay unchanged on every pass. After each image it checks subject, style, composition, text accuracy and constraints, then iterates with one targeted change. Only the selected finals are copied into the workspace; previews are just shown inline. The CLI fallback, scripts/image_gen.py, needs the openai Python package and an OPENAI_API_KEY, and writes under output/imagegen/; the agent never switches to it on its own. The openai/skills repository is marked deprecated; its README points to openai/plugins for current Codex skills.

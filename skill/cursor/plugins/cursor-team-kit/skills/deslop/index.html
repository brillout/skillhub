deslop

Use it when
a branch written with an agent is done and you want its machine-written habits cleaned out before review
It does
reads the diff against main and edits out comments, try/catch blocks, any casts and nesting that don't match the surrounding code
You get
small, behavior-preserving edits and a summary of one to three sentences
Part of
cursor-team-kit, one of the plugins in Cursor's plugin repo
Unlike
unslop, from the same repo, which rewrites prose rather than code

TLDR

A short cleanup pass. The agent checks the current branch's diff against main and removes what the branch introduced that reads as machine-written: comments that are unnecessary or don't match the file's style, defensive checks and try/catch blocks that are unusual for trusted code paths, casts to any that only get around type errors, deeply nested code that early returns would flatten, and other patterns out of keeping with the file and the codebase. It keeps behavior unchanged unless it's fixing a clear bug, prefers small focused edits to broad rewrites, and keeps its closing summary to one to three sentences.

Remove AI code slop

Check the diff against main and remove AI-generated slop introduced in the branch.

Focus Areas

  • Extra comments that are unnecessary or inconsistent with local style
  • Defensive checks or try/catch blocks that are abnormal for trusted code paths
  • Casts to any used only to bypass type issues
  • Deeply nested code that should be simplified with early returns
  • Other patterns inconsistent with the file and surrounding codebase

Guardrails

  • Keep behavior unchanged unless fixing a clear bug.
  • Prefer minimal, focused edits over broad rewrites.
  • Keep the final summary concise (1-3 sentences).

baoyu-compress-image

Use it when
images are too large and you want them smaller, or converted to WebP
It does
runs a bundled script that uses the first of sips, cwebp, ImageMagick or Sharp it finds
You get
WebP files at quality 80 by default, or PNG or JPEG, with each file's size before and after
Watch out
it replaces the original unless you pass --keep
Needs
Bun or npx

It replaces the original file unless you ask it to keep it.

TLDR

A small utility. It takes one file or a whole folder, recursively if asked, and writes each result at the same path with the new extension, or wherever you point it. Quality runs from 0 to 100. Defaults for the format, the quality and keeping originals can be set in a preferences file, and it can report in JSON.

Image Compressor

Tool auto-selection order: sips → cwebp → ImageMagick → Sharp.

Script Directory

{baseDir} = this SKILL.md's directory. Resolve ${BUN_X}: bun if installed; else npx -y bun; else suggest installing bun. Replace {baseDir} and ${BUN_X} with actual values.

Script Purpose
scripts/main.ts Image compression CLI

Usage

${BUN_X} {baseDir}/scripts/main.ts <input> [options]
${BUN_X} {baseDir}/scripts/main.ts image.png                    # → WebP, replaces original
${BUN_X} {baseDir}/scripts/main.ts image.png -f png --keep      # keep PNG format and original
${BUN_X} {baseDir}/scripts/main.ts ./images/ -r -q 75           # directory, recursive

Output: image.png → image.webp (245KB → 89KB, 64% reduction)

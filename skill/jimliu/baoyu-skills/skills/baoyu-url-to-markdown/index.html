baoyu-url-to-markdown

Use it when
you want a web page saved as a Markdown file, including pages that need a login or a CAPTCHA
It does
loads the page in Chrome with its bundled baoyu-fetch tool, using adapters for X, YouTube transcripts and Hacker News threads, and Defuddle for other pages
You get
a Markdown file under url-to-markdown/<domain>/<slug>/, optionally with its images and videos downloaded and relinked
Logins
a wait mode lets you log in or solve a CAPTCHA in the browser, then carries on
Needs
Bun, and Chrome or Chromium
Unlike defuddle
Kepano's defuddle skill runs a command-line tool on a URL; this one drives a real browser and has site adapters

TLDR

Before its first conversion it asks a few setup questions, such as whether to download media and where to save, and stores the answers; it never assumes them silently. If the fetcher's packages aren't installed yet, it installs them with Bun first. The fetcher runs Chrome headless by default and prints Markdown, or writes Markdown or JSON to a file. For pages that need you, one wait mode notices a login or CAPTCHA and continues once it's cleared, another waits for you to press Enter. It can reuse a Chrome that's already running with its debugging port open, or a profile you name. Because headless captures sometimes return thin content without any error, the agent checks the saved Markdown after each headless run against a quality checklist. A debug option saves the captured HTML and network log.

CLI Setup

The CLI source is vendored in {baseDir}/scripts/lib; scripts/package.json installs only third-party runtime dependencies.

  1. {baseDir} = this SKILL.md's directory
  2. ${BUN} = bun if installed; otherwise suggest installing Bun
  3. If {baseDir}/scripts/node_modules is missing: ${BUN} install --cwd {baseDir}/scripts
  4. ${READER} = {baseDir}/scripts/baoyu-fetch (substitute everywhere below)

Usage

${READER} <url>                                          # headless, markdown to stdout
${READER} <url> --output article.md --download-media     # save with local media
${READER} <url> --wait-for interaction --output a.md     # login/CAPTCHA: auto-detect and continue
${READER} <url> --wait-for force --output a.md           # manual: Enter to continue
${READER} <url> --format json --output a.json
${READER} <url> --adapter youtube --output transcript.md

Quality Gate

Headless capture is provisional: some sites silently return low-quality content with exit code 0. Inspect the saved markdown after every headless run, using references/quality-gate.md for the checklist, recovery steps, and capture modes.

Output Path

baoyu-fetch does not generate paths; the agent builds one and passes it to --output:

  1. Base dir: EXTEND.md default_output_dir or ./url-to-markdown/
  2. Domain from URL (e.g., example.com)
  3. Slug from URL path or page title (kebab-case, 2-6 words)
  4. Path: {base_dir}/{domain}/{slug}/{slug}.md — one directory per URL so media stays isolated
  5. On conflict: {slug}-YYYYMMDD-HHMMSS/{slug}-YYYYMMDD-HHMMSS.md

Downloaded media goes into subdirectories next to the markdown file.

Adapters & Media

references/adapters.md: adapter catalog (X, YouTube, Hacker News, generic), media download flow (ask / always / never), JSON output schema. Read it for adapter-specific questions or media prompts.

Environment Variables

Variable Description
BAOYU_CHROME_PROFILE_DIR Chrome user data directory (or --chrome-profile-dir)

Troubleshooting: Chrome not found → --browser-path. Timeout → raise --timeout. Login/CAPTCHA → --wait-for interaction. Debug → --debug-dir to inspect captured HTML and network logs.

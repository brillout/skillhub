baoyu-markdown-to-html

Use it when
you have a Markdown article and need it as styled HTML for a WeChat Official Account post
It does
runs a bundled converter with one of four themes, handling code highlighting, math, footnotes, alerts, PlantUML, and Mermaid diagrams rendered as images
You get
an .html file next to the Markdown, backing up any older one, and a JSON summary of its title, author, summary and images
Unlike
baoyu-post-to-wechat, from the same repo, it only converts and doesn't publish anything
Needs
Bun or npx; Chrome only for Mermaid diagrams, which otherwise stay as code

TLDR

The four themes are default (centered title, white-on-color section headings), grace (text shadows, rounded cards), simple (minimal, asymmetric rounded corners) and modern (large radius, pill-shaped titles), with 13 color presets or any hex color, and a choice of font and size. The theme comes from your request, then this skill's preferences, then baoyu-post-to-wechat's default theme; if none is set, it asks. If the article contains Chinese, Japanese or Korean text and baoyu-format-markdown is installed, it first offers to run that skill to fix bold markers and spacing. Only when you ask, ordinary external links become numbered citations gathered in a final 引用链接 (reference links) section, while WeChat article links stay inline. The first heading is dropped unless you ask to keep it. Mermaid images are cached in imgs/.mermaid-cache/.

Workflow

Step 0: Pre-check (CJK Content)

Only if the input contains CJK characters AND the baoyu-format-markdown skill is available: ask (AskUserQuestion) whether to format first — it fixes ** bold markers broken by inner punctuation and CJK/English spacing. Agree → run baoyu-format-markdown, use the formatted file. Decline → use the original. No CJK → skip to Step 1.

Step 1: Determine Theme

First match wins:

  1. User-specified (CLI --theme or conversation)
  2. This skill's EXTEND.md default_theme
  3. Cross-skill fallback (only if step 2 has none): default_theme: line in $HOME/.baoyu-skills/baoyu-post-to-wechat/EXTEND.md, if it exists
  4. None → ask (AskUserQuestion) with the Themes table

Theme from EXTEND.md → use it directly, do NOT ask.

Step 1.5: Determine Citation Mode

Default off; don't ask. Enable (--cite) only if the user explicitly asks for "微信外链转底部引用", "底部引用", "文末引用", or passes --cite. When enabled:

  • Ordinary external links are rendered with numbered superscripts and collected under a final 引用链接 section.
  • https://mp.weixin.qq.com/... links stay as direct links and are not moved to the bottom.
  • Bare links where link text equals URL stay inline.

${BUN_X} {baseDir}/scripts/main.ts <markdown_file> --theme <theme> [--cite]

Show htmlPath from the JSON result; mention backupPath if a backup was created.

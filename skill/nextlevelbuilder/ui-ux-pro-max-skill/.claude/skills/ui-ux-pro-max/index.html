ui-ux-pro-max

Use it when
you're designing, building or reviewing an interface and want concrete picks for style, colors, fonts and UX rules

TLDR

UI/UX Pro Max packs design knowledge into searchable data files: 79 styles, 192 product palettes with the reasoning behind them, 74 font pairings, 119 UX guidelines, icons, animation presets and chart types. For a new page or project, the agent describes the product, say "beauty spa wellness service", and gets back a design system: a layout pattern, a style, colors, typography, effects and anti-patterns. Optional 1-10 settings make it bolder or plainer, add more or less motion, and space things out or pack them in for dashboards. Saved, it becomes one master design file for the project, plus optional files for pages that differ, and an existing master is never overwritten without your approval. For narrower questions it searches one area, such as UX rules, colors or your detected stack. Its rules are ranked, with accessibility and touch targets first and charts last. If a search comes back empty, it retries once, then says plainly that it's falling back to general defaults.

TLDR

One of the design skills, written by ClaudeKit, that ship next to ui-ux-pro-max in the UI UX Pro Max repo. Its SKILL.md is a short index: a create command, which tells the agent to build persuasive HTML slides with design tokens, Chart.js and the slide knowledge base, and four references. Deck strategies give 15 structures, from a YC seed deck to a QBR or a webinar, each with an emotional arc, plus the Duarte sparkline that alternates what is with what could be. Layout patterns give slide layouts with their CSS and animation classes, the HTML template gives a full deck with navigation and Chart.js, and the copywriting reference gives formulas such as problem-agitate-solution and AIDA, mapped to slide types, with headline patterns. Three of the references also run the slide search script that lives in design-system. design-system holds the fuller slide workflow and its data, and the design skill has a slides section of its own.

TLDR

One of Caveman's short work patterns, for tasks that ask for proof rather than changes. The agent translates the acceptance conditions into the smallest set of checks that would prove them. It reuses results that are still current for the same repository state, runs focused checks before wider gates, and keeps pass, fail, unavailable and blocked apart exactly. It doesn't edit product code unless the request includes fixes, and once the criteria pass it adds no polish, cleanup or unrelated tests. It stops as soon as the proof is complete, and reports only the commands, their results and any risk left unresolved.

Verify and stop

Translate acceptance conditions into smallest sufficient proof set.

  • Reuse still-current results with matching repository state.
  • Run focused checks before wider gates.
  • Distinguish pass, fail, unavailable, and blocked exactly.
  • Do not edit product code unless verification request includes fixes.
  • Do not add polish, cleanup, or unrelated tests after criteria pass.

Stop immediately when acceptance proof is complete. Report commands, results, and unresolved risk only.

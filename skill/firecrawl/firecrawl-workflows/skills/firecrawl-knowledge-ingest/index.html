firecrawl-knowledge-ingest

Use it when
you want a docs site, help center or support knowledge base saved as files, and plain scraping misses pages behind menus, pagination or a login
It does
opens the portal in Firecrawl's browser, follows the sidebar, next links, pagination and load-more buttons, and scrapes each article as Markdown with its metadata
You get
JSON, Markdown or one merged file, a summary of sections and article counts, failed or restricted pages, sources and rerun inputs
Needs
the Firecrawl CLI and a Firecrawl API key, and access to the portal if it needs a login
Unlike firecrawl-knowledge-base
that one maps and scrapes pages into reference, RAG or training sets; this one clicks through portals that need a browser

TLDR

It inspects the portal's navigation to find sections, categories and article URLs, using Firecrawl's URL map only as a supplement for public pages. Each article keeps its title, section, last-updated date, author and tags, with code examples, tables and formatting preserved and navigation, headers and footers stripped. It tracks progress and page failures and stays within authentication boundaries. It asks up to three questions only when blocked: the portal URL, whether a login is needed, or the output format.

Firecrawl Knowledge Ingest

Use this when a docs portal needs browser navigation, auth, pagination, or JS rendering.

Onboarding Interview

Infer the portal URL, output format, auth needs, and page limit from context. If the portal is clear, proceed immediately.

Ask at most 1-3 concise questions only if blocked, such as the portal URL, whether authentication is required, or the desired output format.

Firecrawl Collection Plan

Use Firecrawl browser to:

  • open the portal and inspect navigation
  • identify sections, categories, sidebar links, and article URLs
  • follow sidebar navigation, next links, pagination, load-more controls, or search
  • scrape article content as markdown
  • extract metadata such as title, section, last updated date, author, and tags

Try Firecrawl map as a supplement for public URLs, but use browser navigation for auth-gated or JS-heavy content.

JSON Shape

Use source, url, extractedAt, totalArticles, and sections[] with article title, url, section, content, and metadata.

Quality Bar

  • Strip nav chrome, headers, and footers.
  • Track extraction progress and page failures.

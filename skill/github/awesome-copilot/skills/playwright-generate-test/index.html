playwright-generate-test

Use it when
you have a scenario to test in a web app and want a Playwright test written for it
It does
carries out the scenario's steps one by one in the browser with the Playwright MCP tools before writing any test code
You get
a TypeScript test using @playwright/test, saved in the tests directory, run and reworked until it passes
Needs
the Playwright MCP server connected, and Playwright in the project to run the test
Unlike playwright-explore-website
which explores a site to find what's worth testing, this turns one scenario you give into a passing test

TLDR

Test code written from a scenario's description alone is a guess about the page. This skill forbids that: the agent may not generate test code prematurely or from the scenario alone. It first performs every step of the scenario itself, one at a time, with the tools of the Playwright MCP server. Only once all steps are done does it write a Playwright test in TypeScript with @playwright/test, based on the session's history of those steps. It saves the file in the tests directory, runs it, and keeps iterating until the test passes. If you don't give a scenario, it asks for one first.

Test Generation with Playwright MCP

Your goal is to generate a Playwright test based on the provided scenario after completing all prescribed steps.

Specific Instructions

  • You are given a scenario, and you need to generate a playwright test for it. If the user does not provide a scenario, you will ask them to provide one.
  • DO NOT generate test code prematurely or based solely on the scenario without completing all prescribed steps.
  • DO run steps one by one using the tools provided by the Playwright MCP.
  • Only after all steps are completed, emit a Playwright TypeScript test that uses @playwright/test based on message history
  • Save generated test file in the tests directory
  • Execute the test file and iterate until the test passes

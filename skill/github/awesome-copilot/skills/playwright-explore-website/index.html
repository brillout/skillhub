TLDR

You give a URL, or the agent asks for one. It navigates there with the Playwright MCP server, picks three to five core features or user flows, and interacts with them. Along the way it documents what it did, the relevant UI elements with their locators (the way a test finds an element on the page) and the outcomes expected. It closes the browser context when it's done, summarizes its findings, and proposes and generates test cases based on the exploration.

Website Exploration for Testing

Your goal is to explore the website and identify key functionalities.

Specific Instructions

  1. Navigate to the provided URL using the Playwright MCP Server. If no URL is provided, ask the user to provide one.
  2. Identify and interact with 3-5 core features or user flows.
  3. Document the user interactions, relevant UI elements (and their locators), and the expected outcomes.
  4. Close the browser context upon completion.
  5. Provide a concise summary of your findings.
  6. Propose and generate test cases based on the exploration.

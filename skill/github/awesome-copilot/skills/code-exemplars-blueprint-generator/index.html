code-exemplars-blueprint-generator

Use it when
you want a guide to your codebase's best files that developers can follow when adding features
It does
finds well-structured, documented files for each pattern or layer, such as domain models, controllers, components or tests, and says what makes each exemplary
You get
exemplars.md with a table of contents, sections by pattern, layer or file type, up to three examples each by default, and closing recommendations
Set first
project type or auto-detect, scan depth, how to group examples, how many per group, and whether to add snippets and comments
Only real files
every path must exist in the repo; no hypothetical examples

TLDR

A configurable prompt for GitHub Copilot. It detects your languages and frameworks, or takes the one you set among .NET, Java, JavaScript, TypeScript, React, Angular and Python, and looks for files with clear naming, good documentation, proper error handling and no code smells. It checks categories per stack, such as .NET repositories, services, controllers and middleware, frontend components, state management and forms, Java JPA entities and JUnit tests, or Python ORM models, and across layers: presentation, business logic, data access and cross-cutting concerns like logging, error handling and auth. Each exemplar gets its path, why it's exemplary and the pattern it represents, plus key implementation details and a short snippet when those options are on. A comprehensive scan also notes consistent patterns, architecture, conventions and places where the code departs from best practice.

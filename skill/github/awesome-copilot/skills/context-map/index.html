context-map

Use it when
you're about to change a codebase and want to see everything the task touches before any edit
It does
searches for related files, follows their imports and exports, and finds affected tests and similar code to follow
You get
a Markdown context map: tables of files to modify, dependencies, tests and reference patterns, plus a risk checklist
Then
stops: implementation waits until you've reviewed the map
Unlike refactor-plan
from the same repo, which plans the phased steps of a refactor; this only lists what's involved

TLDR

A short pre-implementation step. Given your task, the agent searches the codebase for related files, identifies their direct dependencies through imports and exports, finds the tests that cover the affected code and looks for similar patterns already in the code. It reports all of this as a context map: the files to modify with their purpose and the changes needed, dependent files that may need updates, test files and what they cover, reference files whose patterns to follow, and a risk checklist for breaking public API changes, database migrations and configuration changes. The skill ends by telling the agent not to implement anything until the map has been reviewed.

description: 'Generate a map of all files relevant to a task before making changes'

Context Map

Before implementing any changes, analyze the codebase and create a context map.

Task

{{task_description}}

Instructions

  1. Search the codebase for files related to this task
  2. Identify direct dependencies (imports/exports)
  3. Find related tests
  4. Look for similar patterns in existing code

Output Format

## Context Map

### Files to Modify
| File | Purpose | Changes Needed |
|------|---------|----------------|
| path/to/file | description | what changes |

### Dependencies (may need updates)
| File | Relationship |
|------|--------------|
| path/to/dep | imports X from modified file |

### Test Files
| Test | Coverage |
|------|----------|
| path/to/test | tests affected functionality |

### Reference Patterns
| File | Pattern |
|------|---------|
| path/to/similar | example to follow |

### Risk Assessment
- [ ] Breaking changes to public API
- [ ] Database migrations needed
- [ ] Configuration changes required

Do not proceed with implementation until this map is reviewed.

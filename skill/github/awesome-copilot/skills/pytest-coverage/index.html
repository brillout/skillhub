pytest-coverage

Use it when
you want a Python project's tests, or one module's, to cover every line of code
It does
runs pytest --cov with an annotate report, opens the annotated copy of each file under 100%, and adds tests for the lines marked with !
You get
new tests and a cov_annotate folder of annotated source, with the loop repeated until all lines are covered
Needs
pytest set up in your project with its --cov coverage option working

TLDR

A short loop for raising test coverage in Python. The agent generates a report with pytest --cov --cov-report=annotate:cov_annotate, narrowed to one module with --cov=<module> or to particular test files if you want. The annotate report writes one copy of each source file into cov_annotate, with every line the tests never ran marked by a leading !. Files already at 100% are skipped; for the rest, the agent reads the marked lines, adds tests that run them, and reruns the report until nothing is left uncovered. The skill says nothing about test style, fixtures or assertions: its target is line coverage only.

Frontmatter
name: pytest-coverage
description: 'Run pytest tests with coverage, discover lines missing coverage, and increase coverage to 100%.'

The goal is for the tests to cover all lines of code.

Generate a coverage report with:

pytest --cov --cov-report=annotate:cov_annotate

If you are checking for coverage of a specific module, you can specify it like this:

pytest --cov=your_module_name --cov-report=annotate:cov_annotate

You can also specify specific tests to run, for example:

pytest tests/test_your_module.py --cov=your_module_name --cov-report=annotate:cov_annotate

Open the cov_annotate directory to view the annotated source code. There will be one file per source file. If a file has 100% source coverage, it means all lines are covered by tests, so you do not need to open the file.

For each file that has less than 100% test coverage, find the matching file in cov_annotate and review the file.

If a line starts with a ! (exclamation mark), it means that the line is not covered by tests. Add tests to cover the missing lines.

Keep running the tests and improving coverage until all lines are covered.

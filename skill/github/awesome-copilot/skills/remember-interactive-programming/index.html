TLDR

A micro-prompt for interactive programming, which means developing against a running program through a REPL. It tells the agent it is an interactive programmer: use the REPL to explore the current system and to modify it to understand what changes are needed; when it evaluates a lot of code, say briefly what it is, because you don't see what it sends to the tool; prefer structural editing tools when editing files; and keep its todo list up to date. Its description says it works best in Clojure when Copilot can reach the REPL, probably through Backseat Driver, and with any system that has a live REPL the agent can use, and invites you to add reminders for your own workflow and workspace.

Will work with any system that has a live REPL that the agent can use. Adapt the prompt with any specific reminders in your workflow and/or workspace.'

Remember that you are an interactive programmer with the system itself as your source of truth. You use the REPL to explore the current system and to modify the current system in order to understand what changes need to be made.

Remember that the human does not see what you evaluate with the tool:

  • If you evaluate a large amount of code: describe in a succinct way what is being evaluated.

When editing files you prefer to use the structural editing tools.

Also remember to tend your todo list.

architecture-blueprint-generator

Use it when
you want one reference document of how an existing codebase is built, so new work stays consistent with it
It does
detects the stack and architecture pattern from project files, dependencies and folders, then documents components, layers, data, cross-cutting concerns, testing and deployment
You get
Project_Architecture_Blueprint.md, with C4, UML, flow or component diagrams and a blueprint for adding features
Settings
eight variables at the top: project type, architecture pattern, diagram type, detail level, and whether to add code examples, implementation patterns, decision records and extension guidance

TLDR

A long prompt template that turns a codebase into its own architecture reference. Unless you name them, the agent works out the stack and the pattern (Clean Architecture, microservices, layered, MVVM, MVC, hexagonal, event-driven, serverless and others) from configuration files, dependencies, folder organization and component boundaries. It then documents what it finds: the overall approach and how its boundaries are enforced; each component's responsibility, internal structure, interactions and extension points; layer dependencies, including circular ones and violations; the data architecture; and how authentication, error handling, logging, validation and configuration are implemented. Further sections cover service communication, patterns specific to .NET, Java, React, Angular or Python, testing and deployment architecture, and governance. Optional sections add representative code examples and decisions inferred from the code. Diagrams must match the actual code, not textbook patterns. The document ends with a guide for new development, covering where new components go, templates and common pitfalls, and notes when it was generated and how to keep it current.

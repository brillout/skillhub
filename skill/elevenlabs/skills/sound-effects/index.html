TLDR

ElevenLabs' own reference for its text-to-sound-effects API. It sets the eleven_text_to_sound_v3 model explicitly, since the API defaults to v2 and v3 follows multi-part prompts more closely and sounds more natural. Parameters set the duration (0.5 to 30 seconds, or automatic), how closely to follow the prompt (0 to 1, default 0.3) and whether the sound loops seamlessly. It lists the output formats, from MP3 and Opus to raw PCM, WAV and telephony μ-law, and gives prompt tips: be specific (heavy rain on a tin roof rather than rain), combine elements, name a style such as 8-bit or a cinematic braam, and set the mood. As with the other ElevenLabs skills, a missing key sends the agent to the CLI's onboarding first.

ElevenLabs Sound Effects

Generate sound effects from text descriptions — supports looping, custom duration, and prompt adherence control.

Setup, before writing any code: if ELEVENLABS_API_KEY isn't set for this project, run npx -y @elevenlabs/cli@latest onboard init from the app's folder first and follow what it prints: it signs the user in and stores a key for the project, so nobody copies one by hand. Otherwise see the Installation Guide. For JavaScript, use @elevenlabs/* packages only.

Quick Start

Python
from elevenlabs import ElevenLabs

client = ElevenLabs()

audio = client.text_to_sound_effects.convert(
    text="Thunder rumbling in the distance with light rain",
    model_id="eleven_text_to_sound_v3",
)

with open("thunder.mp3", "wb") as f:
    for chunk in audio:
        f.write(chunk)
JavaScript
import { ElevenLabsClient } from "@elevenlabs/elevenlabs-js";
import { createWriteStream } from "fs";

const client = new ElevenLabsClient();
const audio = await client.textToSoundEffects.convert({
  text: "Thunder rumbling in the distance with light rain",
  modelId: "eleven_text_to_sound_v3",
});
audio.pipe(createWriteStream("thunder.mp3"));
CLI
elevenlabs text-to-sound-effects convert \
  --text "Thunder rumbling in the distance with light rain" \
  --model-id eleven_text_to_sound_v3 \
  --output thunder.mp3

Parameters

Parameter Type Default Description
text string (required) — Description of the desired sound effect
model_id string eleven_text_to_sound_v2 Model to use. Set eleven_text_to_sound_v3 (SFX v3) explicitly: it follows multi-part prompts more closely, handles music and vocals better, and sounds more natural
duration_seconds number | null null (auto) Duration 0.5–30s; auto-calculated if null
prompt_influence number | null 0.3 How closely to follow the prompt (0–1)
loop boolean false Generate a seamlessly looping sound

Examples with Parameters

# Looping ambient sound, 10 seconds
audio = client.text_to_sound_effects.convert(
    text="Gentle forest ambiance with birds chirping",
    model_id="eleven_text_to_sound_v3",
    duration_seconds=10.0,
    prompt_influence=0.5,
    loop=True,
)

# Short UI sound, high prompt adherence
audio = client.text_to_sound_effects.convert(
    text="Soft notification chime",
    model_id="eleven_text_to_sound_v3",
    duration_seconds=1.0,
    prompt_influence=0.8,
)

pcm_44100 Raw uncompressed CD quality

ulaw_8000 μ-law 8kHz — telephony

Prompt Tips

  • Be specific: "Heavy rain on a tin roof" > "Rain"
  • Combine elements: "Footsteps on gravel with distant traffic"
  • Specify style: "Cinematic braam, horror" or "8-bit retro jump sound"
  • Mention mood/context: "Eerie wind howling through an abandoned building"

Error Handling

try:
    audio = client.text_to_sound_effects.convert(text="Explosion")
except Exception as e:
    print(f"API error: {e}")

Common errors:

  • 401: Invalid API key
  • 422: Invalid parameters (check duration range, prompt_influence range)
  • 429: Rate limit exceeded

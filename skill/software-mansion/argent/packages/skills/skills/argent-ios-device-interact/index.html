TLDR

Part of Software Mansion's Argent toolkit, which lets the agent control simulators, emulators and devices. A physical iPhone supports only some of Argent's tools, and this skill is the short contract for it, read alongside argent-device-interact. Observation never changes the screen: describe and await-ui-element fail on a backgrounded app instead of bringing it forward, while gestures and the keyboard bring it back, after which the agent describes again. Launching, opening or restarting an app makes it the app Argent automates; reinstalling clears that and a tool-server restart forgets it, so the agent launches it again. On hardware the agent has app launch and reinstall, describe, screenshots and screenshot diffs, gestures, the home and volume buttons, the keyboard, waits, run-sequence and the e2e tools. Any other device tool fails with a bare "not supported on ios device", and the skill's list, not the error, says what to do instead: with no orientation change, shake, paste, permission tool, screen recording, debugger or profiler, the phone is moved by hand, text is typed with the keyboard, permissions are changed in its Settings, and debugging, profiling and recording happen on a simulator. Cable, trust and signing problems go to argent-ios-device-setup.

Physical iPhone interaction

Read this only for a physical iPhone. argent-device-interact still applies for everything not listed here.

Contract

  • Observation never changes the screen; mutation may. describe and await-ui-element fail on a backgrounded target instead of re-fronting it; await-screen-idle returns settled: false with no reason. The first describe within a second of button home can still return the old tree; describe again. Gestures and keyboard re-front it and return reactivated: true; re-describe before the next step.
  • launch-app, open-url and restart-app set the app under automation; reinstall-app clears it; a tool-server restart forgets it: launch again.
  • Each tool's description states its own hardware limits (named keys, buttons, edge swipes, tap counts). A gated tool fails with a bare not supported on ios device: the fix is in the list below, not in the error.

Tools on hardware

  • Only these exist: list-devices, launch-app, restart-app, reinstall-app, open-url, describe, screenshot, screenshot-diff, gesture-tap, gesture-swipe, gesture-custom, gesture-pinch, gesture-rotate, button (home, volumeUp, volumeDown, actionButton on models that have one), keyboard, await-ui-element, await-screen-idle, run-sequence, the e2e tools, stop-simulator-server and stop-all-simulator-servers (session end). Every other device tool fails with not supported on ios device.
  • No rotate (the orientation tool), shake, paste, settings-permissions, screen recording, debugger-*, react-profiler-*, native-profiler-*, native-*, boot-device: move the phone by hand, type with keyboard, change permissions in the phone's Settings, and debug, profile or record on a simulator.

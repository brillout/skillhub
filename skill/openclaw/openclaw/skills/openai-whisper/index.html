openai-whisper

Use it when
you want a transcript or subtitles of an audio file without sending it to a cloud service
It does
runs the whisper CLI locally with the model size and output format you need, such as txt or srt
You get
transcript files in the folder you name, or a translation with --task translate
Needs
the whisper command, installed with Homebrew's openai-whisper; no API key
Models
turbo by default on this install; smaller ones are faster, larger ones more accurate

Needs the whisper CLI; it downloads its speech models to ~/.cache/whisper on first run.

TLDR

A short OpenClaw guide to the command-line version of OpenAI's Whisper speech recognition. The agent runs whisper on the audio file, picks a model and an output format, and writes the result to the directory you choose, for example a plain-text transcript or an srt subtitle file. Adding --task translate gives a translated transcript instead. Everything runs on your machine: the models download to ~/.cache/whisper the first time, and the skill notes that smaller models trade accuracy for speed.

Whisper (CLI)

Use whisper to transcribe audio locally.

Quick start

  • whisper /path/audio.mp3 --model medium --output_format txt --output_dir .
  • whisper /path/audio.m4a --task translate --output_format srt

Notes

  • Models download to ~/.cache/whisper on first run.
  • --model defaults to turbo on this install.
  • Use smaller models for speed, larger for accuracy.

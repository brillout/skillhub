openai-whisper-api

Use it when
you want a transcript of an audio file, with speakers labelled if you like, and don't mind sending it to OpenAI
It does
uploads the file to OpenAI's transcription endpoint with a bundled script, using gpt-4o-transcribe unless you pick mini, diarize or whisper-1
You get
a text file beside the audio or wherever --out points, or the JSON response with --json
Needs
an OpenAI API key, curl and Node.js; OPENAI_BASE_URL can point it at a compatible proxy or local gateway
Limits
25 MB per file on the hosted API, in formats such as mp3, m4a, wav and webm
Unlike
openai-whisper, which runs Whisper on your machine with no key, this one transcribes in OpenAI's cloud

Needs an OpenAI API key; your audio is uploaded to OpenAI, or to the endpoint you set in OPENAI_BASE_URL.

TLDR

A wrapper around OpenAI's /v1/audio/transcriptions endpoint. The agent runs the skill's transcribe.sh on an audio file, and the script writes the transcript beside it as a .txt file unless --out names another path. Flags pick the model, set the language, add a prompt with hints such as speaker names, or keep the JSON. The diarize model labels who is speaking, and the script writes each segment as a speaker: text line; that model doesn't take a prompt. The key comes from OPENAI_API_KEY or the skill's entry in OpenClaw's config file.

OpenAI transcriptions API

Transcribe audio through /v1/audio/transcriptions. Set OPENAI_BASE_URL for an OpenAI-compatible proxy or local gateway.

Quick start

{baseDir}/scripts/transcribe.sh /path/to/audio.m4a

Defaults:

  • Model: gpt-4o-transcribe
  • Output: <input>.txt

Useful flags

{baseDir}/scripts/transcribe.sh /path/to/audio.ogg --model gpt-4o-transcribe --out /tmp/transcript.txt
{baseDir}/scripts/transcribe.sh /path/to/audio.ogg --model gpt-4o-mini-transcribe
{baseDir}/scripts/transcribe.sh /path/to/audio.ogg --model gpt-4o-transcribe-diarize --json
{baseDir}/scripts/transcribe.sh /path/to/audio.ogg --model whisper-1
{baseDir}/scripts/transcribe.sh /path/to/audio.m4a --language en
{baseDir}/scripts/transcribe.sh /path/to/audio.m4a --prompt "Speaker names: Peter, Daniel"
{baseDir}/scripts/transcribe.sh /path/to/audio.m4a --json --out /tmp/transcript.json

Notes:

  • Supported upload formats include mp3, mp4, mpeg, mpga, m4a, wav, webm.
  • 25 MB upload limit on the hosted API.
  • Use diarize for speaker labels; script sends chunking_strategy=auto and rejects --prompt.

API key

Set OPENAI_API_KEY, or configure it in the active OpenClaw config file ($OPENCLAW_CONFIG_PATH, default ~/.openclaw/openclaw.json). Optionally set OPENAI_BASE_URL:

{
  skills: {
    "openai-whisper-api": {
      apiKey: "OPENAI_KEY_HERE",
    },
  },

TLDR

A very short OpenClaw guide to nano-pdf, a command-line tool that applies an edit described in plain language to a specific page of a PDF. The agent passes the file, the page and the instruction, for example changing the title to Q3 Results and fixing a typo in the subtitle on page 1 of a deck. The skill warns that the tool's page numbering depends on its version, so an edit that lands on the wrong page should be retried with the other numbering, and that the output should be checked before it's sent anywhere.

nano-pdf

Use nano-pdf to apply edits to a specific page in a PDF using a natural-language instruction.

Quick start

nano-pdf edit deck.pdf 1 "Change the title to 'Q3 Results' and fix the typo in the subtitle"

Notes:

  • Page numbers are 0-based or 1-based depending on the tool's version/config; if the result looks off by one, retry with the other.
  • Always sanity-check the output PDF before sending it out.

TLDR

A short OpenClaw command list for blogwatcher, a command-line tool that keeps track of blogs and RSS or Atom feeds. The agent adds a blog with a name and URL, lists the tracked blogs, scans them all for updates, lists the articles found, marks one article or all of them read, and removes a blog. The example output shows a scan reporting, for each blog, the source type, such as RSS, and how many posts it found and how many are new. For anything else, the skill sends the agent to blogwatcher's own --help.

blogwatcher

Track blog and RSS/Atom feed updates with the blogwatcher CLI.

Install

  • Go: go install github.com/Hyaxia/blogwatcher/cmd/blogwatcher@latest

Quick start

  • blogwatcher --help

Common commands

  • Add a blog: blogwatcher add "My Blog" https://example.com
  • List blogs: blogwatcher blogs
  • Scan for updates: blogwatcher scan
  • List articles: blogwatcher articles
  • Mark an article read: blogwatcher read 1
  • Mark all articles read: blogwatcher read-all
  • Remove a blog: blogwatcher remove "My Blog"

Example output

$ blogwatcher blogs
Tracked blogs (1):

  xkcd
    URL: https://xkcd.com

$ blogwatcher scan
Scanning 1 blog(s)...

  xkcd
    Source: RSS | Found: 4 | New: 4

Found 4 new article(s) total!

Notes

  • Use blogwatcher <command> --help to discover flags and options.

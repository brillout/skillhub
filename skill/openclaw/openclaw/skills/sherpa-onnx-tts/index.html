sherpa-onnx-tts

Use it when
you want spoken audio from text without sending the text to a cloud service
It does
runs a wrapper script in the skill folder that calls sherpa-onnx's offline text-to-speech with your voice model
You get
a WAV file, tts.wav unless you name another
Voice
Piper's US English lessac voice by default; other models from sherpa-onnx's tts-models release work too
Needs
the sherpa-onnx runtime for macOS, Linux or Windows, a voice model, and Node for the wrapper
Unlike sag
it runs offline with no account, where sag uses ElevenLabs' cloud voices

Setup is written for OpenClaw: the runtime and voice model download into ~/.openclaw and their paths go in OpenClaw's config; elsewhere, set SHERPA_ONNX_RUNTIME_DIR and SHERPA_ONNX_MODEL_DIR yourself. Its wrapper script runs on Node.

TLDR

A local text-to-speech skill from OpenClaw, built on sherpa-onnx's offline command-line TTS. Setup downloads the sherpa-onnx runtime for macOS, Linux or Windows and a voice model, by default Piper's en_US lessac voice in high quality, then records both folders as SHERPA_ONNX_RUNTIME_DIR and SHERPA_ONNX_MODEL_DIR in OpenClaw's config file. The agent then runs the wrapper script that ships in the skill folder with the text and an output path, and gets a WAV file. If a model folder holds more than one .onnx file, you name the one to use; the tokens file and data folder can be overridden too. For another voice, you download a different model from sherpa-onnx's tts-models release.

sherpa-onnx-tts

Local TTS using the sherpa-onnx offline CLI.

Install

  1. Download the runtime for your OS (extracts into $OPENCLAW_STATE_DIR/tools/sherpa-onnx-tts/runtime, default ~/.openclaw/tools/sherpa-onnx-tts/runtime)
  2. Download a voice model (extracts into $OPENCLAW_STATE_DIR/tools/sherpa-onnx-tts/models, default ~/.openclaw/tools/sherpa-onnx-tts/models)

Resolve the active state directory first:

STATE_DIR="${OPENCLAW_STATE_DIR:-$HOME/.openclaw}"

Then write those resolved paths into the active OpenClaw config file ($OPENCLAW_CONFIG_PATH, default ~/.openclaw/openclaw.json):

{
  skills: {
    entries: {
      "sherpa-onnx-tts": {
        env: {
          SHERPA_ONNX_RUNTIME_DIR: "/path/to/your/state-dir/tools/sherpa-onnx-tts/runtime",
          SHERPA_ONNX_MODEL_DIR: "/path/to/your/state-dir/tools/sherpa-onnx-tts/models/vits-piper-en_US-lessac-high",
        },
      },
    },
  },
}

The wrapper lives in this skill folder. Run it directly, or add the wrapper to PATH:

export PATH="{baseDir}/bin:$PATH"

Usage

{baseDir}/bin/sherpa-onnx-tts -o ./tts.wav "Hello from local TTS."

Notes:

  • Pick a different model from the sherpa-onnx tts-models release if you want another voice.
  • If the model dir has multiple .onnx files, set SHERPA_ONNX_MODEL_FILE or pass --model-file.
  • You can also pass --tokens-file or --data-dir to override the defaults.
  • Windows: run node {baseDir}\\bin\\sherpa-onnx-tts -o tts.wav "Hello from local TTS."

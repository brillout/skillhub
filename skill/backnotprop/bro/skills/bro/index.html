bro

Use it when
the agent's last reply was dense or full of jargon and you want it said simply
It does
restates that message more simply and concisely, like one human talking to another
You get
a plain-language version of the same reply; the agent's style for later replies doesn't change
Runs
only when you call it
Part of
backnotprop/bro, a set of small alignment skills such as readback, recap and status

TLDR

The whole skill is one instruction: restate your last message, stop using jargon, speak coherently, and say it more simply and concisely, like one human talking to another. It acts on a single reply. Unlike output-style modes that stay on for the session, you call it each time a reply loses you, and the agent goes back to its usual voice afterwards. Its frontmatter turns off automatic invocation, so the agent never applies it on its own.

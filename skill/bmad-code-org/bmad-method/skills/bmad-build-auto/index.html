Skill 13 of 24 in the BMad Method bundle · Before it: bmad-build · After it: bmad-code-review

Only works inside its bundle: Its workflow is printed by a script in the _bmad/ folder that the bmad skill's setup creates, so it does nothing without that setup. Install BMad Method instead.

Needs uv, BMad set up in the project and subagents; it halts as blocked without them.

TLDR

The unattended twin of bmad-build, called by name, usually by an orchestrator. It takes one ticket from BMad's ticket tree, a plan file or a description, and never moves on to another. It follows the same path: check that the working tree is clean, investigate, write a plan file with acceptance criteria and verification commands, implement in the session for a change of about 100 lines or fewer or through a fresh subagent for a larger one, run the verification commands, have a reviewer subagent read the diff (four for a thorough review), verify each finding, patch what this change caused, defer older problems in the plan and commit locally without pushing. The invocation can pin the route or the review level, including no review, and can ask it to halt after planning. Wherever a person would be asked, it stops instead: an intent gap, a plan that fails its readiness standard, failing verification or a dirty tree each end the run as blocked, with the reason written to the plan file. A built or done plan handed back to it gets a fresh review pass.

name: bmad-build-auto
description: 'Implements one story, feature, or bug fix end to end without human interaction: plan, code, review, verify, report status. Use when invoked by name, usually by an orchestrator'

Run the following command exactly once without changing the current working directory.

Replace {project-root} with the nearest folder containing _bmad/, from the working directory upward. Replace {skill-root} with the absolute path to this skill's directory.

uv run --no-cache "{project-root}/_bmad/scripts/render_skill.py" --project-root "{project-root}" --skill "{skill-root}"
  • When the invocation names a route (oneshot or full), append --set workflow.route=<value> to the command.
  • When the invocation names a review selection (none, quick, or thorough; "skip review" or "no review" mean none), append --set workflow.review=<value> to the command.
  • The command prints the skill's workflow: follow it. HALT: <reason>: report the reason and stop.
  • If the script does not exist, BMad is not set up in this project yet. Offer to set it up using bmad skill, then run the command again. If you do not have the bmad skill, offer to install it first.
  • On any other output or failure, including uv being unavailable, report the command output and stop. Do not run any workflow source directly.

TLDR

BMad's walkthrough treats your attention as scarce: it shows only what you need to see and keeps its bookkeeping out of the session. It first works out what the target is and what it's for, reading the ticket when one covers it, then the plan, PR description and commit messages, and asks until it knows. The narrative opens with the intent, quoted from the ticket when there is one, then three to five entry points to open first, then one block per concern that leads with the mechanism and links the exact places, and ends with docs and other small enablers. Every file reference is clickable. On each block it suggests one to three moves, answers your questions with references, and rewrites a block in another shape if you ask, remembering that for later blocks. When you finish a block it shows the next one, checks the finished one off, and asks whether to commit if the tree is dirty. A background subagent writes the files when one is available. At the end it guesses the follow-through, such as merging the PR, and asks before doing it.

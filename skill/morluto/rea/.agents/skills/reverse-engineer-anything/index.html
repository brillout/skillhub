TLDR

REA, short for Reverse Engineer Anything, is one MCP server for reverse engineering. Installing the skill adds only instructions, except through REA's Claude Code or Codex plugin, which registers the server too. The skill tells the agent which tool fits the target: an ASAR or JavaScript tree, an archive or installer, an Android APK, a .NET assembly, firmware, WebAssembly, Go or Rust binaries, crash reports, model files, SQLite snapshots, saved HAR or packet captures, or a browser or Electron app already open. Native code goes through Ghidra, IDA or Kuna. It starts from summaries and pages into retained evidence instead of repeating an analysis. For broad questions it turns the request into a checklist, keeps a ledger of findings, and can split independent questions across parallel workers. Static analysis is never presented as observed execution; runtime tools, such as debuggers, Frida scripts or scripted browser clicks, run only the target and actions you asked for. When tools are missing or the connection drops, it diagnoses the actual blocker instead of re-running setup. It asks which app you mean rather than picking one, and ends by explaining the findings in plain language and closing its sessions.

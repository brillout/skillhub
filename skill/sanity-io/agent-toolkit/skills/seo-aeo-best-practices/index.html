TLDR

Sanity's guide to optimizing for classic search engines (SEO) and for AI answer engines (AEO), which pick one source to quote rather than ranking pages. The SKILL.md defines both and EEAT, Google's framework of experience, expertise, authoritativeness and trustworthiness, then sends the agent to one of four references. Technical SEO covers titles, meta descriptions, Open Graph, sitemaps, canonical URLs, redirects, performance, robots.txt and hreflang. Structured data gives JSON-LD patterns for articles, FAQs, organizations, products and breadcrumbs, combined in one @graph, with testing tools. EEAT covers showing who wrote a page, their credentials, dates and contact details, with a Sanity author schema. The AEO reference says to answer first and explain after, use question headings, lists, tables and FAQ pairs, keep content fresh and cited, and decide deliberately whether GPTBot, ClaudeBot, PerplexityBot and Google-Extended may crawl, since blocking them keeps content out of AI training but may cost citations. Code examples use Sanity schemas, GROQ and Next.js.

SEO & AEO Best Practices

Principles for optimizing content for both traditional search engines (SEO) and AI-powered answer engines (AEO). Includes Google's EEAT guidelines and structured data implementation.

When to Apply

Reference these guidelines when:

  • Implementing metadata and Open Graph tags
  • Creating sitemaps and robots.txt
  • Adding JSON-LD structured data
  • Optimizing content for featured snippets
  • Preparing content for AI assistants (ChatGPT, Perplexity, etc.)
  • Evaluating content quality using EEAT principles

Core Concepts

SEO (Search Engine Optimization)

Optimizing content to rank well in traditional search results (Google, Bing).

AEO (Answer Engine Optimization)

Optimizing content to be selected as authoritative answers by AI systems.

EEAT (Experience, Expertise, Authoritativeness, Trustworthiness)

Google's framework for evaluating content quality.

References

Start with the one reference that matches the task, such as technical SEO, structured data, EEAT, or AI-answer readiness. See references/ for detailed guidance:

  • references/eeat-principles.md — EEAT implementation and author schema
  • references/structured-data.md — JSON-LD patterns (Article, FAQ, Breadcrumb, Product)
  • references/technical-seo.md — Technical SEO checklist (metadata, sitemaps, hreflang, robots.txt)
  • references/aeo-considerations.md — AI/AEO considerations (AI Overviews, crawler management)

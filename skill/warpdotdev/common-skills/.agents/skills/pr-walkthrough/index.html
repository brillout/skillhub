pr-walkthrough

Use it when
you have a pull request's branch checked out and want a map of what it touches before reading the diff
It does
reads the PR, its diff, changed specs, review comments and the surrounding code, then draws a system overview plus data-flow, dependency and user-action graphs
You get
.warp/pr-walkthrough/index.html: one self-contained page that opens from a file:// URL, with zoom, search, keyboard shortcuts and links into the PR's diff
Unlike a review
it adds no findings or verdict; anything it notices is framed as an area to inspect
Needs
the GitHub CLI, gh, and Playwright with Chromium for its bundled validator; the page loads D3 7.9.0 from jsDelivr
Looks like
Warp's brand: dark surfaces, pink accents and Matter fonts, from Warp's hosted guide through the brandalf skill, or built-in fallback values

Styled in Warp's brand. Publishing to a public Cloudflare Pages URL happens only when you ask, and needs a Cloudflare account.

TLDR

An experiment in reading a PR on a canvas instead of a diff. The agent finds the current branch's PR with gh and collects the diff, description, changed specs, and human and agent review comments, then reads the full changed files and their neighbours so explanations rest on the real code, not just the hunks. It builds four views a reviewer toggles between: a system overview of cards that explains the touched subsystem without mentioning the PR, a data-flow graph, a code dependency graph and a user-action graph, each graph with directed, labelled edges, and every view with a guided tour. Size follows the PR: a tiny change gets two or three nodes per view. Screenshots, mocks and Figma exports are saved into the site's assets rather than hotlinked, and each changed file links to its anchor in the PR's Files changed tab. Bundled Python scripts, which its commands call at .agents/skills/pr-walkthrough/scripts/ in your repo, generate the page and check it in a browser; it isn't called ready until that passes, and without a browser it's reported as unverified. On request it publishes the folder to Cloudflare Pages with wrangler.

update-skill

Use it when
you're creating a skill, or reworking an existing one's frontmatter, structure or guidance
It does
sets the rules: a kebab-case name, and a third-person description that starts with a verb and says what the skill does and when
You get
a SKILL.md kept under about 200 lines, with detailed material moved to a references folder
Unlike skill-creator
which runs evals to test and improve skills, it gives authoring rules, and testing means trying the skill on similar tasks

TLDR

Warp's house guide for skill files. Frontmatter needs a kebab-case name and a description that starts with an action verb, is written in the third person, says both what the skill does and when to use it, and includes the terms that should trigger it. The body usually has a title and summary, an optional overview, the steps or instructions, and optional best practices and example PRs. Past about 200 lines, detail moves into a references folder linked from SKILL.md. Its best-practices reference covers loading in stages (name and description always, the body when the skill triggers, references only when needed), keeping references one level deep, cutting what the agent already knows, naming the language of code blocks, numbered steps with checklists for ordered work, gerund names such as processing-pdfs, and anti-patterns like vague descriptions, too many options and dated advice. To revise a skill, it says to watch where the agent struggles, fix those sections, then try the skill on similar tasks. Checking frontmatter with the skills-ref library is optional. Its examples point to Warp skills, such as add-feature-flag, that aren't in this repo.

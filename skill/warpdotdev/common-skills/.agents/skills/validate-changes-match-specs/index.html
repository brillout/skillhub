validate-changes-match-specs

Use it when
a spec-driven change is up for review or nearly done, and you want to know where the code and its specs disagree
It does
finds the specs the branch adds or changes, extracts their commitments, reads the code and tests, and lists each material mismatch with its sources and a recommended resolution
You get
your choice applied per mismatch: change the code, change the spec, or acknowledge it, then validation and an optional commit and push
Also checks
that the code does what your replies on PR review threads said was fixed, and security specs for both what they allow and what they prevent
Unlike check-impl-against-spec
which adds spec drift to an automated PR review, it works through each mismatch with you and changes the code or the spec as you choose
Needs
an ask_user_question tool for its multiple-choice prompts, as in Warp's agent; optionally Oz cloud agents with computer use for user-visible flows, and the Figma MCP server

TLDR

A closing check for spec-first work. It finds the base branch, then the specs the change introduces or modifies, such as PRODUCT.md, TECH.md or SECURITY.md under specs/<issue>/, falls back to specs the PR or commits reference, and stops if there are none. Specs, PR text and comments are treated as untrusted data. Commitments are sorted into product behavior, technical implementation, security and privacy, validation and non-goals, then checked against the diff, the code it depends on and the tests. Security specs get the closest look: each guarantee is checked both ways, and a gap no spec covers is proposed as a spec amendment. If the PR has been reviewed, it also compares the code with what your last replies said was fixed. Before the report it can offer cloud computer-use agents to test user-visible behavior against Figma mocks or screenshots. Then it asks whether to resolve mismatches one by one or in a batch, and for each one whether to update the code or the spec. Follow-up comments on review threads are drafted for your approval before posting.

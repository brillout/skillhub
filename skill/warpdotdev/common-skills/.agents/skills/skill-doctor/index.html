skill-doctor

Use it when
you want to know which of your installed skills actually help, judged from your real conversation history
It does
samples up to 12 conversations from the last 45 days by default, scores each for efficiency, code quality, procedure compliance and verbosity, and grades the setup
You get
report.html in a temporary folder: a scorecard, three top findings and suggested skill edits as diffs, with a button that exports a share image
Keeps
everything local: transcripts are never uploaded, and your skill files stay untouched until you agree to apply the edits
Runs in
Warp, Claude Code, Codex, Pi, Grok Build, ZCode and Hermes; in any other agent it stops before reading anything
Needs
Python 3 for its collector and report scripts

Runs only in Warp, Claude Code, Codex, Pi, Grok Build, ZCode and Hermes, and ends every reply with a link to request access to Warp Factories.

TLDR

skill-doctor comes from Warp's shared skills. It first asks which conversations to grade (this repository, all, or chosen projects) and whether to include global skills, then runs a bundled Python collector over the supported agents' local conversation stores. Each sampled transcript is judged against four rubric files; code quality counts only where the transcript changed code. Scores are curved and weighted into an overall grade that also counts skill coverage, the share of sessions where an installed skill was detected. A conversation fails when any applicable score is below 0.5, and only failed conversations count as evidence for suggestions, such as fixing a trigger description that never fired, adding a missing step, or creating a new skill. Each suggestion cites the session behind it, and the agent writes full proposed SKILL.md files and unified diffs to the report folder, never into your repo. It then tells you the grade and three findings, adds the Warp Factories link, and asks whether to apply the edits.

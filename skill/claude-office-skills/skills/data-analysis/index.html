data-analysis

Use it when
you have an Excel or CSV file and want to know what's in it, answer a question about it, or need a formula or chart
It does
describes the dataset and its quality issues, summarizes its statistics and trends, and picks a chart type for each kind of data
You get
Markdown write-ups in fixed shapes: a dataset overview, a statistical summary, an insight report with recommendations, and formula, chart, pivot-table and cohort specs
Formulas
for Excel and Google Sheets, such as SUMIFS or VLOOKUP, with each argument explained and where to put it
Limits

TLDR

From Claude Office Skills. You share a spreadsheet and say what you're after: an overview, an answer to a specific question such as revenue by region or whether two columns correlate, a chart, or a formula. The agent answers in the skill's templates. A dataset overview lists rows, columns and date range, each column's type, completeness and sample values, and flags missing values and likely duplicates. A statistical summary gives mean, median, standard deviation and range with findings, and an insight report opens with an executive summary, then key metrics, trends and recommendations. Chart choices follow a table: line for trends, pie for part of a whole, bar for comparisons, histogram for distributions, scatter for correlation, map for geography. It also specifies pivot tables and cohort tables, and lays out sales, customer and financial analyses as sequences of questions. Its best practices: clean the data first, define each metric, consider seasonality and benchmarks, label charts, don't truncate axes misleadingly, and allow for colorblind readers. Its frontmatter lists spreadsheet, chart and pivot-table tools of the repo's office-mcp server, but its instructions never call them, and every output is a Markdown write-up.

Best Practices

For Better Analysis
  1. Clean data first: Handle missing values, duplicates
  2. Define metrics clearly: What exactly are you measuring?
  3. Consider context: Industry benchmarks, seasonality
  4. Validate findings: Cross-check with other data sources
For Better Visualizations
  1. Keep it simple: One main message per chart
  2. Label clearly: Title, axes, legend
  3. Use appropriate scale: Don't truncate misleadingly
  4. Consider colorblind users: Use patterns or distinct colors

Limitations

  • Cannot directly execute code on your data
  • Large datasets may need sampling
  • Complex statistical models need specialized tools
  • Real-time data requires live connections
  • Cannot guarantee 100% accuracy on OCR'd data

UI/UX Pro Max Bundle · 6 skills

Use it when
you want one install for building an interface and making its brand material: guidelines, tokens, logos, icons, banners, social images and decks
It does
ui-ux-pro-max picks styles, palettes and fonts for the UI; five skills by ClaudeKit keep a brand file in sync with design tokens and generate brand assets
You get
a design system for your interface, brand guidelines synced to token CSS, Gemini-made logos, mockups and SVG icons, PNG banners and social images, and HTML decks
Needs
Python 3 and Node for the scripts, and a Gemini API key and two Python packages for design's logos, mockups and icons

TLDR

Its best-known skill, ui-ux-pro-max, searches local data on styles, palettes, font pairings and UX rules to give the agent a design system for the interface it builds. The repo's installer, uipro init, and its Claude Code plugin put design skills written by ClaudeKit next to it, and those lean on one another. brand keeps docs/brand-guidelines.md as the source of truth and syncs its colors into design-tokens.json and design-tokens.css. design-system layers tokens into primitive, semantic and component values, flags hardcoded ones in your code, and builds HTML decks that must import the token CSS; slides is a thin index whose references run design-system's slide search. design is the hub for brand assets: it hands brand, token and component work to its siblings, generates logos, identity mockups and SVG icons with Gemini, offers a logo gallery made with ui-ux-pro-max, and builds banners and social images in HTML, the social images by way of brand, design-system and ui-ux-pro-max. banner-design is a fuller, self-contained version of its banner workflow. Both installs also add ui-styling, for shadcn/ui and Tailwind setup.

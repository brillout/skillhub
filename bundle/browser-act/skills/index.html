TLDR

BrowserAct is a browser-automation service for AI agents, and these skills use its local CLI rather than its cloud product. browser-act lets the agent open pages in your own Chrome, reusing your logins, or in BrowserAct's stealth browsers, which each present their own device fingerprint so sites see separate, ordinary visitors rather than a bot. The agent reads a numbered list of page elements and clicks or types by number, takes screenshots, captures network responses, and can send you a live link to take over when it gets stuck. browser-act-skill-forge builds on browser-act, which it loads first. You describe the data you want from a site and confirm a plan; it works out how the site loads that data, preferring the site's own data APIs over scraping its HTML, then generates a skill of SKILL.md plus Python scripts, has a subagent test it, fixes what fails and installs it. Later runs call that skill without exploring again, which suits bulk jobs such as hundreds of listings. Beyond the free account, only managed proxies and more than five stealth browsers cost money.

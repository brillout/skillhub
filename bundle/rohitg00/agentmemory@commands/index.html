agentmemory Bundle · 8 skills

Use it when
you want your coding agent to keep decisions across sessions, pick up where you left off, or find out why code changed
It does
gives the agent commands over agentmemory's store: save, search and delete memories, resume, list or recap past sessions, and trace commits to sessions
You get
memories tagged to be found again, a catch-up on your last session, timelines of past sessions and commits traced to their sessions, all as the tools returned them
Start with
handoff when a session starts without context, recall to search, and remember to save
Needs
agentmemory's memory server, set up with npx @agentmemory/agentmemory, and its MCP tools; the session views also need its capture hooks, from a plugin or native integration
Installs with

Unlike planning-with-files

TLDR

agentmemory is a memory server for coding agents, and these eight skills are the commands that work on its store through its MCP tools. remember saves a fact or decision with concept tags chosen to be found again, recall searches those memories and the session activity agentmemory captured, and forget deletes chosen memories once you confirm. handoff resumes the latest session for this project, leading with any question left open; session-history lists recent sessions, and recap groups a time window's sessions by date with highlights. commit-history lists commits linked to agent sessions, and commit-context traces a line, function or file back to the commit and session behind it. The session views read what agentmemory's capture hooks recorded, which installing the skills or connecting the MCP tools alone doesn't turn on, and commits are linked to sessions only when an integration records them; agentmemory's own plugin hooks don't. Each skill works alone, and they share one rule: show only what the tools returned, so an empty result is reported plainly, with other search terms or filters to try, never filled in from guesses.

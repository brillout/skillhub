TLDR

Two skills from Warp's shared repo for an automated review step. review-pr does the review: from the annotated diff and the PR description it writes review.json, with a verdict, a summary and inline comments that each start with CRITICAL, IMPORTANT, SUGGESTION or NIT, and checks it with a bundled validator. When there's a spec, in spec_context.md from the workflow or from review-pr's own resolve_spec_context.py script when the prompt points to it, review-pr hands the comparison to check-impl-against-spec if it's installed. That skill lists the spec's commitments, compares them with the code, and adds only material drift to the same review.json: missing behavior, contradictions, significant unplanned scope, or a skipped validation or migration step, each at least an important concern. Neither posts to GitHub; the workflow publishes the file.

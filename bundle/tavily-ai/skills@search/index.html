tavily-search searches, reads pages and maps or crawls sites through Tavily; tavily-research splits a big question into subtopics and researches each through tavily-search

TLDR

Tavily's search and research skills split web work by size. tavily-search handles any task that needs the web: it uses Tavily's MCP tools when they're connected and the tvly CLI otherwise, runs advanced searches for ten results, follows leads, extracts the pages worth citing, keeps long results in files, and stops once two independent sources agree. When you want an analysis, a comparison across several criteria or an in-depth investigation, it hands the job to tavily-research, installing it first if it's missing. tavily-research splits the question into subtopics that don't overlap and, when subagents are available, gives each its own researcher, which searches through tavily-search and writes a notes file where every finding carries its URL. One writer then turns the notes into reports/{title}.md: the answer first, headings that state findings, inline citations and a conclusion about what the findings imply. Without subagents, the agent researches each subtopic itself and writes the report as its reply.

Claude Code, Codex and Cursor: installs the Tavily CLI, and on a fresh interactive desktop install starts tvly init, which signs you in and adds all six of the repo's skills

curl -fsSL https://cli.tavily.com/install.sh | bash

Claude Code, Codex and Cursor, once the Tavily CLI is installed; signs you in and adds all six of the repo's skills, pinned to the CLI release, so run tvly update first when refreshing them

tvly init

The same without signing in: search and extract work up to a keyless rate limit, map and crawl need a sign-in

tvly init --skip-auth

npx skills add https://github.com/tavily-ai/skills --skill tavily-search --skill tavily-research

TLDR

Strix's skills share one engine: autonomous AI agents that dynamically exploit a target and report only findings proven with a working proof-of-concept. penetration-testing-with-strix is the hub, covering install and the choice between the self-hosted open-source CLI (Docker plus your own LLM key, air-gap capable) and the managed app.strix.ai cloud. Four skills target a specific surface: web-app-penetration-testing for a running site, api-security-testing for REST/GraphQL/gRPC, owasp-top-10-testing for a category-mapped assessment, and find-security-vulnerabilities-in-code for a white-box code review. application-security-testing routes a whole product's assets to the right one and merges the results into a ranked plan. Once a scan reports, fix-security-vulnerabilities-with-strix patches root causes and re-scans to prove each exploit is closed, and ci-security-scanning-with-strix gates every pull request. All share the same SARIF output, so findings line up across local and cloud runs.

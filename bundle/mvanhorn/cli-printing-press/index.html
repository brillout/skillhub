TLDR

CLI Printing Press turns an API, a website or a captured HAR file into a Go command-line tool built for agents, with an MCP server, and its nine skills drive the cli-printing-press binary. printing-press runs the main loop: research, a feature list you approve, generation, shipcheck and live tests against the real API. Inside that run it calls printing-press-output-review, where a subagent judges sampled command output, and printing-press-polish, which fixes what the checks flag without asking and returns the ship, ship-with-gaps or hold verdict that decides whether the CLI reaches your library. printing-press-score regrades a CLI or compares two. printing-press-publish, only on your direct request, revalidates and live-tests the CLI, scans it for secrets and personal data, and opens a pull request to the public library. Later, printing-press-amend turns friction from your session, or your own asks, into a library PR; printing-press-import copies a published CLI back into your library; and printing-press-reprint regenerates one under the current press, importing it first if needed. printing-press-retro mines a run for defects in the press itself and, on Submit, files public issues on mvanhorn/cli-printing-press and uploads scrubbed zips to catbox.moe, a public file host.

Its skills, in the order they're used

The ones marked “Only in the bundle” need the rest of it, so they're only listed here. The others also have their own entry in the skills list.

  1. printing-press

    Only in the bundle 7.8K total downloads

    Researches an API, then generates, live-tests and polishes a Go CLI and MCP server for it from a spec, HAR file or browser capture.

    Invokes printing-press-output-review and printing-press-polish on every run, so both must be installed alongside it.

  2. printing-press-output-review

    Only in the bundle 6.6K total downloads

    Reviews a printed CLI's sampled command output for implausible results that rule-based checks miss, such as irrelevant matches or silently dropped sources.

    Runs only when printing-press or printing-press-polish calls it on a CLI they're checking; it can't be invoked directly.

  3. printing-press-polish

    Only in the bundle 7K total downloads

    Runs diagnostics on a Printing Press CLI, fixes what they flag, and reports the before-and-after scores with a ship verdict.

    Invokes printing-press-output-review during its checks, and works only on CLIs printing-press generated.

  4. printing-press-score

    6.6K total downloads

    Scores a CLI printed by the Printing Press against its Steinberger quality bar, or compares two CLIs side by side.

  5. printing-press-publish

    Only in the bundle 7K total downloads

    Validates, live-tests and packages a Printing Press CLI, then opens a pull request to the public printing-press-library and drives it to green review.

    Publishes only CLIs printing-press generated, and applies the PII-scanning step of the secret-protection reference that ships with printing-press.

  6. printing-press-amend

    Only in the bundle 5.6K total downloads

    Turns friction you hit with a published Printing Press CLI, or your own asks, into a fix and a pull request to its library.

    Changes only CLIs already in the public Printing Press library, and scrubs credentials with the patterns in printing-press-retro's secret-scrubbing reference.

  7. printing-press-import

    Only in the bundle 6.7K total downloads

    Copies a published Printing Press CLI from the public library into your local press library, ready to polish or publish again.

    Fetches only CLIs the press printed and published, into the local press library that printing-press-polish, printing-press-publish and printing-press-reprint work on.

  8. printing-press-reprint

    Only in the bundle 6.6K total downloads

    Regenerates an existing Printing Press CLI under the current press, carrying its prior research, features and post-publish fixes into the new print.

    Hands every run to printing-press, and invokes printing-press-import first when the CLI isn't local.

  9. printing-press-retro

    Only in the bundle 6.6K total downloads

    Reviews a Printing Press run for defects in the press itself, writes a scrubbed retro, and files the serious ones as GitHub issues.

    Only reviews printing-press runs, reading their manuscripts. On Submit it files public issues on mvanhorn/cli-printing-press and uploads scrubbed zips to catbox.moe, a public file host.

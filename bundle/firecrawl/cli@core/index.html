TLDR

firecrawl is the entry point. Its description covers any live-web task, ordinary research included, and it sets an order to escalate in: search first, scrape a URL you already have, map a large site to find the right page, crawl a whole section such as /docs, set up a monitor for repeated checks, and interact with pages that need clicks, forms or a login. Beside that path, agent sends Firecrawl's own AI agent through a complex site to extract structured data, download saves a site as folders of Markdown files, and parse converts local files such as PDFs. For each command, firecrawl sends the agent to a companion skill with its options, costs and rules, such as search's feedback, which refunds a credit, or how to word a monitor's goal. Each companion also works alone and points to its neighbours, such as scrape to interact when a page needs clicks. Search also finds, and scrape runs, tools from Alexandria, Firecrawl's catalog of data providers and site workflows. The same files are copied unchanged into Firecrawl's firecrawl/skills catalog, which skills.sh lists separately.

Web Quality Skills Bundle · 6 skills

Use it when
you want a website checked and fixed for speed, accessibility, search and security, with measured evidence behind each finding
It does
starts with web-quality-audit, one review across every area, then goes deep with one skill per area; each measures, fixes or recommends fixes, and measures again
You get
code fixes, and from the audit a report: an evidence table, issues ranked critical to low with file and fix, a fix order and what's still unverified
Keeps apart

Works with

TLDR

Six skills by Addy Osmani, built on Google Lighthouse, Chrome DevTools and Core Web Vitals; the README calls the collection unofficial. web-quality-audit is the entry point: it settles which pages, states and devices to check, takes a small live baseline, then covers performance, accessibility, SEO, best practices and agentic browsing (how well an AI assistant can understand and operate the page), ending with a ranked report and a fix order. The other five each go deep on one area. performance owns the measurement workflow, which web-quality-audit and core-web-vitals also read: real-user Chrome data (CrUX) decides whether users have a problem, a browser trace or Lighthouse run finds why, and code inspection only forms hypotheses. core-web-vitals targets just LCP, INP and CLS (loading, responsiveness and layout stability) and their thresholds. accessibility tests against WCAG 2.2 with Lighthouse, the accessibility tree and the keyboard. seo covers crawling, indexing, page tags and structured data without promising rankings. best-practices covers security headers, CSP, deprecated APIs and code quality, adding the dependency and header checks Lighthouse lacks. Each re-runs the same checks after its fixes; for speed, real-user confirmation waits for new visits.

TLDR

pstack is the plugin Lauren Tan (poteto) uses to ship code at Cursor, aimed at writing less code of higher quality. how explains what code does through read-only explorer subagents, and why digs through git, PRs and each connected evidence source for the reasons behind it. architect grounds a design with both, has arena sketch it, then writes the code against the chosen sketch. arena has several models attempt the same task, picks a base and grafts in the best of the rest. interrogate reuses arena's fan-out so adversaries try to break a change, keeping only findings a run proves, and blast-radius proves the one fact a risky-looking change is safe because of. technical-writing and unslop hold the prose rules for docs, PR descriptions and replies, and technical-writing runs every doc through unslop. The principle skills are one rule each, such as fix root causes or prove it works, which poteto-mode indexes and the other skills cite by name. The plugin's 44 other skills, among them poteto-mode, setup-pstack, swarm and in-your-own-words, and its two subagents aren't listed here: install the plugin for the full set.

Its skills, in the order they're used

The ones marked “Only in the bundle” need the rest of it, so they're only listed here. The others also have their own entry in the skills list.

  1. how

    6.7K total downloads

    Explains how a part of your codebase works, at the depth a senior engineer needs to onboard, using read-only subagents.

  2. why

    6.4K total downloads

    Digs up why code is built the way it is, from git history, PRs and connected tools, and returns a cited answer.

  3. architect

    Only in the bundle 5.5K total downloads

    Sketches a change's usage, types, signatures and module boundaries with several models before code, then implements against the chosen sketch.

    Runs the how and why skills to ground the design, and the arena skill to sketch it.

  4. arena

    5.6K total downloads

    Has several subagents attempt the same task, then picks a base and grafts in the best parts of the rest.

  5. interrogate

    Only in the bundle 5.3K total downloads

    Has adversary subagents on different models try to break a change or design, keeping only findings that a run proves.

    Runs the arena skill's runner setup, fan-out and verify steps; it also states the intent with in-your-own-words, which comes with the plugin but isn't listed here.

  6. blast-radius

    6.9K total downloads

    Finds what a change could break beyond its diff, and proves the one fact it's safe because of by running real code.

  7. technical-writing

    6K total downloads

    Writes and reviews docs, RFCs, READMEs, PR descriptions and commit messages to a layered standard: Diátaxis, Google developer style, STE and Global English.

  8. unslop

    33.2K total downloads

    Rewrites text to remove AI tells: stock vocabulary, em dashes, filler, hedging, passive voice and mannered prose.

  9. principle-boundary-discipline

    5.1K total downloads

    Puts validation and error handling at system boundaries, trusts internal types, and keeps business logic in pure functions free of the framework.

  10. principle-type-system-discipline

    5.2K total downloads

    Has the agent design types so the compiler rejects impossible states: branded primitives, parsing at boundaries and types derived from schemas.

  11. principle-fix-root-causes

    5.6K total downloads

    Makes the agent fix a bug at the first place the system went wrong, not where the symptom surfaced.

  12. principle-prove-it-works

    5.5K total downloads

    Makes the agent check the real thing before calling a task done, not a proxy, a self-report or "it compiles".

  13. principle-guard-the-context-window

    5.5K total downloads

    Keeps the agent's context from filling up by sending bulk work to subagents and keeping only summaries in the main thread.

  14. principle-encode-lessons-in-structure

    5.6K total downloads

    Makes the agent turn a rule it keeps repeating into a lint, metadata flag, runtime check or script instead of more instructions.

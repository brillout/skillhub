Bright Data scrape and search Bundle · 2 skills

Use it when
the agent needs web data through Bright Data: records pulled from a site, or results for a search query
It does
scrape picks a ready scraper, Scraper Studio or a page fetch for the fields you want; search picks SERP API or a top-100 job by depth
You get
structured records or parsed results, with one line naming the product it chose, which one word from you overrides
Needs
a Bright Data account, and the bdata CLI or, without it, Node.js scripts or REST calls
Installs with
the repo's nine other skills by its default command, among them agent-onboarding, which installs the bdata CLI and logs in once; --skill flags add fewer

TLDR

Bright Data's skills split web data by where a job starts. scrape handles data fields from known places: it checks a bundled table of 25 popular platforms and the free scraper catalogue first, builds a scraper in Scraper Studio when none fits and the pages share a layout, the job repeats or the data needs browser work, and only falls back to fetching raw pages for one-off jobs. search handles anything that starts from a query: SERP API for about ten results in one call, and Web Scraper API jobs for the top 100, Google verticals such as Shopping and Maps, and what ChatGPT Search, Perplexity, Gemini or Google AI Mode say about a brand. Those jobs follow scrape's reference, and search checks their scraper ids with scrape's lookup script, so it needs scrape beside it; plain SERP calls don't. Neither asks you which product to use: each states its choice in one line. Recurring work means a cron job the agent writes, except in Scraper Studio, which has its own scheduler. Logins and refused calls go to the repo's agent-onboarding skill; single pages, ready-made datasets, Instagram and your own browser code go to its other skills.

Summarizes the repo at 103b4cf.

Any agent, with the skills CLI; adds all 11 of the repo's skills, agent-onboarding among them (needs Node.js and git; in Windows PowerShell, use npx.cmd if scripts are blocked)

npx -y skills add brightdata/skills -y

Any agent, with the skills CLI; adds just these two and agent-onboarding, which the README says to start with: it installs the bdata CLI and logs in once

npx -y skills add brightdata/skills -y --skill scrape --skill search --skill agent-onboarding

Without Node.js, as the README suggests: clone the repo, then copy skills/scrape, skills/search and skills/agent-onboarding into the folder your agent reads skills from, often .agents/skills

git clone https://github.com/brightdata/skills

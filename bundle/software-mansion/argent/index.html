you want the agent to use, test, record, debug or speed up your app, React Native above all, on a simulator, emulator, phone or TV

teaches the agent Argent's tools: drive the app by touch or TV remote, check UI flows, diff screenshots, record video, read logs, profile code and offer design variants
You get

Start with

TLDR

Argent is Software Mansion's MCP server for controlling simulators, emulators, phones, TVs and Chromium apps; these twelve skills teach the agent to use it. argent-device-interact is the base: which tool fits each tap, swipe or keystroke, and how to find targets in the element tree. It sends the agent to argent-ios-device-interact for a physical iPhone, which has fewer tools, and to argent-settings-permissions only when the app's own dialog can't change a permission. argent-tv-interact swaps taps for focus moved by remote buttons. argent-test-ui-flow builds on argent-device-interact for manual QA, checking each step with the element tree, logs or a screenshot diff, taken as argent-screenshot-diff describes, then giving a verdict. argent-screen-recording captures a flow as video. argent-metro-debugger attaches to a React Native app's JavaScript runtime through Metro for logs, components, network traffic and running code. Performance work starts at argent-react-native-optimization: subagents fix what lint and a checklist turn up, then argent-react-native-profiler records React commits, with argent-native-profiler alongside by default for native hangs, CPU and leaks; both ask before fixing and re-profile after. argent-lens builds design variants in the running app, lets you pick in Argent's Lens window, then applies your picks. One installer sets up the server and all the repo's skills.

Its skills, in the order they're used

The ones marked “Only in the bundle” need the rest of it, so they're only listed here. The others also have their own entry in the skills list.

  1. argent-device-interact

    29.5K total downloads

    Drives iOS simulators, Android emulators, phones and Chromium apps through Argent: taps, gestures, typing, hardware buttons and screenshots.

  2. argent-ios-device-interact

    Only in the bundle 14.1K total downloads

    Adapts Argent's device control to a physical iPhone: which tools exist on hardware, how a backgrounded app behaves, and what to do instead.

    Covers only what differs on a physical iPhone; argent-device-interact, which sends the agent here for one, still applies to everything else.

  3. argent-tv-interact

    24K total downloads

    Drives TV apps on Apple TV, Android TV and Fire TV through Argent: reads focus, navigates with the D-pad remote, types and takes screenshots.

  4. argent-settings-permissions

    22.2K total downloads

    Grants, denies or resets an app's runtime permissions on an iOS simulator or Android device through Argent, without the Settings UI.

  5. argent-test-ui-flow

    29.4K total downloads

    Tests app UI flows on iOS or Android through Argent, checking each tap or keystroke with screenshots, element trees or logs.

  6. argent-screenshot-diff

    28.1K total downloads

    Compares a baseline and a current screenshot of a running app through Argent to check visual changes and catch visual regressions.

  7. argent-screen-recording

    20.9K total downloads

    Records a video of an app on an iOS simulator or Android screen through Argent while the agent drives the flow.

  8. argent-metro-debugger

    29.4K total downloads

    Connects the agent to a running React Native or Chromium app's JavaScript runtime through Argent, to read logs, components and network traffic.

  9. argent-react-native-optimization

    Only in the bundle 29.6K total downloads

    Optimizes a React Native app's performance with lint and code sweeps, then profiling the running app to find and fix the worst bottlenecks.

    Loads argent-react-native-profiler as its profiling phase, and navigates every screen with argent-device-interact to check that the fixes broke nothing.

  10. argent-react-native-profiler

    29.5K total downloads

    Profiles a React Native app's re-renders and CPU use through Argent, ranks the slowest commits and components, and re-profiles after each fix.

  11. argent-native-profiler

    29.4K total downloads

    Profiles native CPU hotspots, UI hangs and memory issues in iOS and Android apps through Argent, with Instruments or Perfetto.

  12. argent-lens

    25.6K total downloads

    Builds several design variants of on-screen elements, captures each running on the device, and lets you choose in Argent's Lens window.

TLDR

Jakub Krehel's better-* skills split interface quality into six domains, each naming the sibling that owns what it leaves out. better-accessibility checks keyboard and focus behavior, accessible names, forms and announcements against WCAG 2.2. better-layout sets grouping, alignment and reading order, then tests it resized, translated and mirrored. better-writing writes labels, errors and empty states in the product's voice. better-typography sets the type scale, wrapping and punctuation. better-colors builds palettes, names tokens by role and measures contrast. better-ui gives exact values for radii, shadows, icon swaps and animation. Each works alone, in the project's own styling. better-interface runs all six in that order, so polish never hides a basic failure, and merges their findings into one table of at most 15, ranked by severity, then by how far one fix reaches; thirteen symptoms, such as a control with no accessible name, are high severity on sight, and a domain whose skill is missing is marked Not reviewed. For a branch, pull request or uncommitted change, interface-review comes first: it resolves the change, expands it to at most five surfaces that render it, reads deleted lines for lost signals such as an aria-label, labels each finding and hands them to better-interface.

Its skills, in the order they're used

The ones marked “Only in the bundle” need the rest of it, so they're only listed here. The others also have their own entry in the skills list.

  1. interface-review

    Only in the bundle 22.3K total downloads

    Reviews a branch, pull request or uncommitted change for the interface problems it introduced or regressed, marking each finding Introduced, Regression or Pre-existing.

    Hands the change's scope, the surfaces it renders in and a status on every finding to better-interface, which loads the six better-* skills and sets severity, coverage, the cap and the verdict; without better-interface it reports only the resolved scope and file inventory, names the missing skill and stops.

  2. better-interface

    Only in the bundle 34.5K total downloads

    Reviews a screen, flow or whole interface by running the six better-* domain reviews, then merges their findings into one ranked report.

    Loads the six better-* skills as the sources of truth for its domain reviews and marks any it can't load Not reviewed, without recreating its rules, so alone it reviews no domain.

  3. better-accessibility

    34.2K total downloads

    Reviews and fixes keyboard and focus behavior, ARIA, accessible names, forms, announcements, motion and zoom, citing the WCAG 2.2 criterion each failure breaks.

  4. better-layout

    35.4K total downloads

    Sets grouping, alignment, reading order and responsive structure in UI code, then checks it survives resizing, translation and right-to-left mirroring.

  5. better-writing

    33.4K total downloads

    Writes and reviews interface copy, such as buttons, errors, empty states and confirmations, in the product's existing voice and vocabulary.

  6. better-typography

    39.3K total downloads

    Sets and reviews how text renders in UI code: type scale, line-height, letter-spacing, wrapping, truncation, font loading and punctuation.

  7. better-colors

    37.3K total downloads

    Builds and audits color systems: generates ramps with a color library, maps steps to semantic tokens, converts notation and measures contrast.

  8. better-ui

    44.6K total downloads

    Polishes surfaces, icons and motion in UI code with exact values for corner radius, shadows, press scale and animation timing.

TLDR

Waza (技, Japanese for technique) is Tw93's engineering habits turned into skills, each with one job, its red lines and how its result gets checked, refined over 300+ sessions. Every skill stops at the outcome you asked for, and review, diagnosis and audit requests stay report-only until you authorize a change. The README suggests three chains. To plan a feature, think settles the plan, the agent implements it once you approve, in think or by handing the plan to check, and check reviews before merging. To ship a fix, hunt finds the root cause, then check reviews the change and can also commit, push, release and follow up on issues. To research, read fetches sources, learn turns them into notes or an article, and write polishes the prose. health stands apart: it audits Claude Code, Codex or Pi configuration and how maintainable the project is for agents. Each skill works alone, and they hand off where it helps: think sends bug reports to hunt, check sends document review to write, and learn fetches through read. The installs below also add the repo's eighth skill, ui, for frontend design. A statusline and optional always-on rules install separately, from scripts.

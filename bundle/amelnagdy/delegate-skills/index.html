TLDR

Every delegate skill runs the same loop. Your main agent, the orchestrator, writes a self-contained brief, since the implementer sees no chat history, and tells it not to commit. The skill's relay.mjs runs the implementer, never commits, and writes a result.json with the implementer's report, the files git shows as changed and a session id where the CLI has one. The orchestrator then re-runs the project's tests and other checks, reads the diff against the brief and commits what holds, or resumes the session with a short delta brief. Each skill states its implementer's autonomy in that CLI's own terms: Codex's write sandbox, OpenCode's auto-approval, Claude Code's acceptEdits with a shell sandbox, Antigravity's own permission rules. You can skip setup and name an implementer directly, or run delegate-setup once to discover what's installed and write a lane map, globally or for one repo. A delegate skill dispatched with --lane then takes that lane's model and other settings, explicit flags still win, and the wrong skill for a lane fails loudly. The README says the scripts use Node built-ins only, make no network calls of their own and send no telemetry.

Its skills, in the order they're used

The ones marked “Only in the bundle” need the rest of it, so they're only listed here. The others also have their own entry in the skills list.

  1. delegate-setup

    Only in the bundle 6.3K total downloads

    Maps kinds of coding work to the implementer CLIs you have installed, as named lanes, and writes that config after you approve it.

    Only writes the lane map that the repo's delegate skills read when you dispatch with --lane; it never dispatches work itself.

  2. codex-delegate

    8.2K total downloads

    Hands a bounded coding task to the OpenAI Codex CLI, then reviews its diff, re-runs your checks and commits the work itself.

  3. opencode-delegate

    7K total downloads

    Hands a coding task to the OpenCode CLI on a model you approve, then reviews its diff, re-runs your checks and commits it.

  4. claude-delegate

    6.5K total downloads

    Hands a coding task to a separate Claude Code CLI session, then reviews its diff, re-runs your checks and commits the work itself.

  5. agy-delegate

    6.3K total downloads

    Hands a coding task to Google's Antigravity CLI, then reviews its diff, re-runs your checks and commits the work itself.

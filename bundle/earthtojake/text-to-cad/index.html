text-to-cad Bundle · 2 skills

Use it when
you want an agent to design a physical part or a robot and carry it on toward cutting, printing or simulation
It does
cad models parts as Python build123d scripts; the other skills add catalog parts, DXF drawings, fabrication and 3D-printing checks, slicing, printer handoff and robot description files
You get
Python model scripts; STEP, STL, 3MF, GLB, DXF, URDF, SRDF and SDF files; a CAD Viewer that follows every rebuild; preflight and printability reports and printer-ready G-code
Needs
text-to-cad's cad command, which cad, dxf, urdf, srdf and sdf install by curl-to-shell script if missing; Python with trimesh for dfam-check; OrcaSlicer, and Bambu Connect or Studio, for printing
Telemetry
text-to-cad sends usage stats and crash reports by default, never files, paths or prompts, its README says

TLDR

Most of these skills run through text-to-cad's cad command and local server and show results in one CAD Viewer. cad is the core: it writes each part or assembly as a Python build123d function and exports STEP, STL, 3MF or GLB on request. step-parts adds real purchasable parts from the step.parts catalog, which a model reads once converted with cad export. dxf turns a modelled part, a vendor STEP or a fresh sketch into a cut-ready DXF, and sendcutsend checks that DXF or a STEP against SendCutSend's current specs before you order. For 3D printing, dfam-check first measures an exported mesh against the chosen process's limits for walls, overhangs and supports, then gcode slices it with OrcaSlicer, and bambu-labs opens the sliced file in Bambu Connect, where you start the print. For robots, urdf writes the robot's links and joints, each link's mesh exported from its cad model; srdf adds MoveIt planning groups on top of a validated URDF, and sdf writes Gazebo models and worlds, derived from the URDF when there is one. The cad command validates all three, and the viewer poses their joints. Each skill also works alone; one install command adds them all.

macOS and Linux: installs uv if missing, the cad command and CAD's server, and in every agent app it finds the plugin, or the skills alone, with the repo's dfm and engineering-drawing skills too

curl -fsSL https://texttocad.dev/install.sh | sh

Windows, in PowerShell: the same; run it the first time in a terminal of its own, not in a Store app's shell such as the Claude desktop app's

irm https://www.texttocad.dev/install.ps1 | iex

Claude Code plugin, which needs uv; it brings CAD's server and the repo's 2 other skills, dfm and engineering-drawing, and Cursor and Grok Build load it too

claude plugin marketplace add earthtojake/text-to-cad#latest && claude plugin install text-to-cad@earthtojake

Codex plugin, which needs uv; it brings the CAD viewer and the repo's 2 other skills, dfm and engineering-drawing

codex plugin marketplace add earthtojake/text-to-cad --ref latest && codex plugin add text-to-cad@earthtojake

Gemini CLI extension, which needs uv; it brings CAD's server and the repo's 2 other skills, dfm and engineering-drawing

gemini extensions install https://github.com/earthtojake/text-to-cad --ref latest --consent

Any agent without a plugin, with the skills CLI, plus the repo's 2 other skills, dfm and engineering-drawing; cad, dxf, urdf, srdf and sdf need the cad command, which they install with the script above if missing

npx skills add earthtojake/text-to-cad#latest

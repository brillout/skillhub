TLDR

Its core is caveman: the agent leads with the answer in short plain sentences, without greetings, hedging or recaps, until you say "stop caveman". Two stricter modes start only when you type them: ultracave cuts replies to fragments, and megacave turns them into Classical Chinese (文言文), for fewer characters. The other skills carry the idea beyond chat. caveman-commit writes terse Conventional Commits messages, caveman-review writes one line per review finding, and caveman-compress rewrites a memory file such as CLAUDE.md in caveman style to save input tokens, backing up the original. To spare the main context, cavecrew hands searches, small edits and reviews to three subagents that report back compressed, and caveman-explore, a read-only code finder, replies with file and line citations only. caveman-stats shows recorded token usage, and caveman-help lists every mode and command. The agent picks up six short work patterns when a task fits: investigate-first diagnoses before editing, lean-build builds only what's asked, surgical-patch fixes at the narrowest layer, safe-refactor keeps behavior unchanged, migration keeps changes reversible and verify-and-stop proves finished work without adding to it. The repo's CLI and proxy, which shrink what the agent reads, and the skills that drive them aren't in this bundle.

TLDR

The enterprise-search plugin of Anthropic's knowledge-work plugins, built to answer questions such as "what did we decide about the API redesign?" from every work tool you connect. search is the command you call: it checks the connected sources, splits the question into a query per source in that tool's own syntax, runs them in parallel and returns one answer with its sources. The other three skills, which the plugin's README says power the search experience, go deeper on each step and load on their own. search-strategy classifies the question, such as a decision, status or policy query, writes keyword and semantic variants, translates filters such as from: and after:, scores results and broadens empty searches. source-management detects which sources are connected, says how to add missing ones, orders sources by question type and handles rate limits. knowledge-synthesis merges the same fact found in several places, cites every claim, rates confidence by freshness and authority, and flags conflicts rather than picking one version. Installing the plugin also adds digest, a daily or weekly roundup of action items, decisions and mentions across the same sources, which isn't listed here.

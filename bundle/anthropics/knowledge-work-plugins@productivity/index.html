TLDR

The productivity plugin of Anthropic's knowledge-work plugins, kept in files in your working folder. start checks the folder for TASKS.md, CLAUDE.md, memory/ and dashboard.html and creates what's missing. On a first run it asks where you keep your todos, goes through them asking what each nickname, acronym and codename means, can scan your chat, email, documents and calendar for more, then writes CLAUDE.md and the memory/ files. From then on, task-management keeps TASKS.md as you add, finish and ask about tasks, and memory-management decodes each request from CLAUDE.md, then the glossary and memory files, then by asking you, saving what you tell it to remember. dashboard.html, copied from the plugin, is a board on the same TASKS.md that you open yourself. update pulls tasks assigned to you from a project tracker or GitHub Issues and offers to add them, flags overdue tasks, tasks Active for 30 days or more and tasks with no person or project for triage, and asks about people and projects memory lacks. With --comprehensive it also scans chat, email, documents and calendar for todos you haven't captured and new people or projects. update never adds tasks or memories without your confirmation.

Summarizes the repo at ab4cb1c.

Claude Code plugin; also adds the dashboard and MCP connections to Slack, Notion and project trackers such as Asana, Linear and Jira

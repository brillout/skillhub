Use it when
you want an agent to run a deep learning research repo from its README and record honestly what worked
It does
finds the smallest documented run, such as one evaluation command, sets it up, runs it and audits the result, instead of a full training run
You get
a repro_outputs/ folder: a verdict (verified, partial or blocked), the exact commands, logs, patches, any change to data, evaluation or metrics, and the README annotated section by section
Main skill
ai-research-reproduction runs a reproduction end to end and works alone; six of the others are steps it uses as needed, and each can be called by name
Exploration lane
ai-research-explore, explore-code and explore-run try new ideas on a saved baseline, only when you ask, and never report them as reproduced
Also has

Needs
Python 3.11+ and Git for the main skill's scripts; five of the other skills load a runtime, writer or reference from it, so install it with them

TLDR

ai-research-reproduction is the entry point, and the README offers it as a self-contained install. It picks the smallest documented target (inference, then evaluation, then a training startup check; full training only after you confirm) and runs it through its script in three calls: plan, run, verify. Six skills are steps it uses as needed, and each can also be called by name. repo-intake-and-plan sorts the README's commands and recommends the first run. env-and-assets-bootstrap plans a conda environment and where checkpoints and datasets go. paper-context-resolver answers one gap the README leaves, such as a dataset split, from the paper, and notes any conflict. analyze-project maps a repo's entry points and configs, read-only, when its structure is unclear. minimal-run-and-audit records an inference or evaluation run in repro_outputs/, and run-train starts, checks or resumes training, recording it in train_outputs/. When a run fails, safe-debug diagnoses it and patches only with your approval. Exploration is a separate lane, only when you ask and from a saved baseline: ai-research-explore ranks ideas and hands code changes to explore-code, which works on an isolated branch, and short trials to explore-run. Their results go to explore_outputs/ as candidates, never as reproduced results.

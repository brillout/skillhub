TLDR

A capture-the-flag solving suite whose skills share one repo and install together. solve-challenge is the user-invocable entry point: it runs first-pass recon (file, strings, nc, HTTP probes), detects the CTF platform (CTFd API token flow, or Playwright MCP for JS-rendered sites), decides the dominant category, then loads the matching ctf-* skill. Each category skill (web, pwn, crypto, reverse, forensics, osint, malware, ai-ml, misc) is a deep, self-contained reference of techniques for that category and also works on its own. ctf-writeup runs after a solve to turn the session into a standardized submission writeup. The install pulls the whole repo, which also ships ctf-similar-search, a Tavily-API writeup-search helper that ctf-web's notes point to when stuck; SkillHub does not list it as a separate skill. The repo also ships scripts/install_ctf_tools.sh to install the many CLI tools these skills call.

Its skills, in the order they're used

The ones marked “Only in the bundle” need the rest of it, so they're only listed here. The others also have their own entry in the skills list.

  1. solve-challenge

    Only in the bundle 9.5K total downloads

    Triages a CTF challenge, identifies its category, and routes to the matching ctf-* skill; the suite's recon and dispatch entry point.

    The suite's user-invocable entry point; runs recon then loads the ctf-* category skills, which it expects installed alongside it.

  2. ctf-web

    10.3K total downloads

    Exploits web CTF targets: SQLi, XSS, SSTI, SSRF, XXE, JWT, auth bypass, file upload, deserialization, prototype pollution and OAuth/SAML flaws.

  3. ctf-pwn

    10K total downloads

    Turns memory-corruption bugs in CTF binaries into code execution: buffer overflows, format strings, heap, ROP, shellcode, kernel and sandbox escapes.

  4. ctf-crypto

    9.8K total downloads

    Breaks cryptography in CTF challenges: RSA, AES, ECC, lattices and LWE, PRNGs and classical ciphers, with ready attack recipes.

  5. ctf-reverse

    10.8K total downloads

    Reverse-engineers compiled, obfuscated, packed or virtualized CTF targets (binaries, APKs, WASM, firmware, custom VMs, bytecode) to understand them before exploiting.

  6. ctf-forensics

    9.6K total downloads

    Analyzes disk images, memory dumps, PCAPs, logs and steganography in CTF challenges to recover hidden data, files and flags.

  7. ctf-osint

    9.7K total downloads

    Gathers open-source intelligence for CTF challenges: geolocation, reverse image search, username enumeration, DNS and archive recon, and public-record lookups.

  8. ctf-malware

    9.2K total downloads

    Analyzes malware and network traffic in CTF challenges: obfuscated scripts, C2 protocols, PE/.NET binaries, shellcode and anti-analysis tricks.

  9. ctf-ai-ml

    8.2K total downloads

    Attacks ML models in CTF challenges: adversarial examples, model extraction, membership inference, LoRA exploitation, data poisoning and LLM jailbreaks.

  10. ctf-misc

    9.4K total downloads

    Solves CTF challenges that fit no main category: pyjails, encodings, RF/SDR, esoteric languages, QR/audio puzzles, constraint solving and game theory.

  11. ctf-writeup

    8.4K total downloads

    Generates a standardized submission-style writeup after you solve a CTF challenge, with metadata, solution steps, code and lessons learned.
